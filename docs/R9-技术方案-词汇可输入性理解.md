# R9 技术方案 · 词汇「可输入性理解」(词力通 2.0:语境化学 + 接收/产出双维实测 + 跨模块复现)

> 承接 R5(词汇并入:`VocabularyWord`/`VocabularyLearning`/`vocab_node·question·wrong`/`vocab_list`)。
> 目标:把"背孤立词→点认识"升级为"**在真实语境里学到能接收能产出、跨语境迁移、并在所学内容里反复遇见**"。
> 原则:**直接复用长难句已建的理解验证框架**(`llm_provider.complete_json` 分档+智能重试、`mastery_judge_service.bkt_update`、诊断干扰项、产出 rubric、迁移检索、间隔重现、`usage_log_service` 台账+预算熔断)。扩字段 + 缓存探针 + 双维掌握,不破坏现有背词前台。

---

## 0. 现状关键事实(已核实)
- `VocabularyWord`(d5)= 公共词典:`word/phonetic/definitions/examples([{en,zh}])/phrases/difficulty/type/source/frequency/star/image_urls/en_description/audio…`。**已有例句/短语**,可作语境与产出参考。
- `VocabularyLearning`(d5)= 个人背词 **SM-2**(`interval_days/repetitions/easiness_factor/next_review_at/level/is_wrong/wrong_count`)——**单轴、再认导向**,无接收/产出之分,无语境探针结果。
- 边表(d18):`vocab_question(word_id,q_scope,question_id,source=stem|option|explanation)`、`vocab_wrong(word_id,wrong_record_id)`、`vocab_node(word_id,node_id)`。→ **每个词的"真实出现语境"系统已知**(差异化地基)。
- 词单来源(R5):个人体系命中词 / 通用词库 / 教材词 / 候选(作业·试卷·手动)。
- 长难句侧已落地可复用件:`complete_json`(finish_reason 智能重试+模型分档)、`bkt_update`(蒙对不误判/答错回拉/连对达标)、诊断干扰项构造、`grade_translation` 维度 rubric、`find_transfer_sentence` 迁移检索、`student_ls_review` 间隔重现、`llm_usage_log`+预算熔断。

## 1. 核心定义(操作化)
- **可输入性理解(接收维)** = 在**新语境**里读/听到该词能即时理解(可理解输入,Krashen i+1)。
- **真正掌握** = 接收维达标 **且** 产出维达标 **且** 通过**同词新语境迁移** **且** **延迟仍对**。
- 每词的掌握 = 两个概率:**接收掌握 `recep`** + **产出掌握 `prod`**(各由对应探针 BKT 更新)。阈值默认 0.85。

## 2. 词汇知识维度(探针设计地基,简化自 Nation)
形(拼写/发音/词形)· 义(核心义 + **语境义** + 多义辨析)· 用(搭配/词性句型/语域/近义辨析);两方向:接收 / 产出。

---

## 3. 三层方案

### 3.1 学 —— 用语境喂(可理解输入)
- **先语境后义**:优先用**该词对该生的真实语境句**(`vocab_question`→题干 / `vocab_wrong`→错题原句),退 `VocabularyWord.examples`,再退 LLM 现生成 i+1 例句。
- **多样语境**:同词 2-3 个不同句子轮替;深度分层展开 形音→语境义→搭配→多义。

### 3.2 测 —— 接收 + 产出,诊断性,拒绝再认
**接收探针(`recep`)**:① 语境 cloze(新句挖空,选/填)② 多义辨义(同词两句各问义)③ 听音辨义。
干扰项**诊断化**:形近词 / 近义词 / 该词他义 → 选错暴露具体误区。
**产出探针(`prod`)**:① 用该词造句 / 补全(LLM rubric:义对?搭配对?词性/语法对?)② 中→英情境产出 ③ 选搭配 ④ 跟读发音(复用现有评分,形/音维)。
**判定**:词"掌握" = `recep≥.85 且 prod≥.85 且 过迁移 且 过延迟`。

### 3.3 记 —— 间隔 + 真实复现
- **间隔重现**:错/产出失败缩短间隔;双维达标才毕业(SM-2 调度可保留,叠加 BKT 双维门槛)。
- **交错**:不同词、不同题型混练。
- **真实复现(本系统独有)**:学生学的**长难句/真题/作业**里若出现其词单未掌握词 → 高亮 + 轻测(incidental review),真实语境复现。市面 App 无此能力。

## 4. 新增 / 改动

### 4.1 扩 VocabularyWord(迁移 m113)
- `probes_json JSONB null`:**公共可复用探针库**(LLM 预生成并缓存):
  `{cloze:[{sentence,blank,options,answer,misconceptions}], sense:[…多义辨析…], collocation:[…], produce_hint}`。

### 4.2 扩 VocabularyLearning(迁移 m113)
- `mastery_recep Numeric(5,4) null`、`mastery_prod Numeric(5,4) null`(BKT 双维掌握度);
- `transfer_ok bool default false`(过同词新语境迁移)。SM-2 字段保留(调度+兼容)。

### 4.3 服务 `vocab_probe_service.py`(新,大量复用长难句件)
- `pick_context(db, student_id, word_id)`:真实语境优先(vocab_question/vocab_wrong → 句子)→ examples → LLM。
- `generate_probes(word, context)`:出接收+产出探针 + 诊断干扰项;复用 `complete_json`(feature=`vocab_probe`,走 `fast_model()`)缓存进 `probes_json`。
- `comprehension_probes(word, student)`:取该词探针集(接收 1-2 + 产出 1)。
- `submit_probe(db, student, word_id, kind, answer)`:客观题字符串判分 / 产出走 LLM rubric;逐结果 `mastery_judge_service.bkt_update` 更新 `recep`/`prod`;错→`is_wrong/wrong_count`+错词本+间隔重现;返回 {correct, misconception, recep, prod}。
- `find_transfer_context(word)`:同词**另一个**语境句(其它 vocab_question / 另一 example / LLM)→ 迁移检测。
- `word_mastery(...)` / `backfill_probes(...max_tokens_budget)`(复用预算熔断)。

### 4.4 背词主流程改造(`vocabulary_service`)
学词卡:**先给语境句**(挖空/高亮该词)→ 学生确认义 → 接收探针 → (进阶)产出探针;"学会一个词"= 探针过关而非点"认识"。掌握度展示改为 接收/产出 双维。

### 4.5 跨模块真实复现(R9.4)
`incidental_vocab_hits(db, student, text)`:文本里命中该生词单未掌握词 → 返回可内联轻测的词;长难句/真题页学习后顺势触发。

### 4.6 API(学生端)
- `GET /vocab/{word_id}/probes` → {context, probes[](无答案), recep, prod}
- `POST /vocab/{word_id}/probe` {kind, answer} → {correct, misconception, recep, prod, mastered}
- `GET /vocab/{word_id}/transfer` + `POST /vocab/{word_id}/transfer-submit`(同词新语境,R9.3)
- `GET /long-sentences/{id}/vocab-hits`(R9.4 复现)

### 4.7 Admin
- `POST /admin/vocab/probe-backfill`(批量生成探针,带 token 预算熔断 + 结果条);用量自动进 LLM 看板(feature=`vocab_probe`)。

---

## 5. 为什么强于市面 App(差异化)
① 用学生**自己材料/课程语境**学和测(个性化可理解输入)② 测**语境理解+产出**而非再认 ③ 多义/搭配/用法深度 ④ **跨语境迁移 + 延迟 + 在长难句/真题里真实复现** ⑤ **接收/产出双维 BKT**,掌握度可信。

## 6. 决策点【✅ 已定 2026-06-25】
1. **语境句来源优先级 = 学生真实原句 > 教材/词典例句 > LLM 兜底**。即 `vocab_wrong`(错题原句)> `vocab_question`(作业/试卷优先,真题次之)> `VocabularyWord.examples` > LLM 现生成。最个性化、最贴学生自己语料。
2. **产出探针按脚手架分层**:入门档可选、进阶/挑战档必做(对齐长难句 tier)。R9.1 只做接收探针,本决策在 R9.2 生效。
3. **探针库公共复用**:`probes_json`(题型/诊断干扰项/多义辨析)同词全平台**共享一套缓存**;**个性化只在语境句层**(`pick_context` 用学生自己的句子做题面)。即「**题型公共、语境个性**」——既省 LLM 成本又保留个性化。

## 7. 分步实施(每步可验收、可独立提交)
- **R9.1 语境化学 + 接收探针**:m113(probes_json + recep/prod 列);`vocab_probe_service`(pick_context/generate_probes/submit 接收部分 + recep BKT);背词卡先语境后义;探针端点。
- **R9.2 产出探针**:造句/搭配(LLM rubric)+ prod BKT;"掌握"需双维;backfill + 预算熔断 + admin。
- **R9.3 多义/搭配深度 + 迁移项**:多义辨析探针 + 同词新语境迁移(transfer_ok)。
- **R9.4 双维调度 + 跨模块复现**:BKT 双维驱动间隔;长难句/真题里命中词单未掌握词的 incidental 轻测。

## 8. 验收
- 同一词连续答对接收探针 N 次后 `recep` 跨阈值判"可输入性理解";单次蒙对不误判;答错回拉(BKT 行为)。
- 产出探针维度评分正确(义/搭配/词性);"掌握"需接收+产出双过 + 迁移 + 延迟。
- 语境句优先取自学生真实材料(vocab_question/wrong)。
- 探针生成走 fast 档 + finish_reason 智能重试 + 预算熔断;用量入 LLM 看板(feature=vocab_probe)。

## 9. R9.1 数据流(细化)—— 语境化学 + 接收探针

> R9.1 只做**接收维**(可输入性理解);产出/迁移留到 R9.2/9.3。一句话:**用学生自己的句子做题面 + 复用该词缓存的诊断干扰项 → 答对错驱动接收掌握度(BKT)**。

### 9.1 本步数据模型(迁移 m113)
- `VocabularyWord` 加 `probes_json JSONB null`(R9.1 写 distractors/misconceptions/cloze_fallback/sense)。
- `VocabularyLearning` 加 `mastery_recep / mastery_prod Numeric(5,4) null` + `transfer_ok bool default false`(R9.1 只用 `mastery_recep`,其余留空给 R9.2/9.3,避免二次迁移)。

### 9.2 探针库结构(`probes_json`,词级公共复用,决策③)
```jsonc
{
  "distractors": ["interesting","interested","interview"],     // 形近/近义/他义,词级,所有学生复用
  "misconceptions": { "interesting":"这是形容词,句中需名词", "interview":"形近词,意思不同" },
  "cloze_fallback": [{ "sentence":"Banks pay you ___ on your savings.", "answer":"interest" }], // 无学生语境时兜底
  "sense": [   // 仅多义词;definitions 多于 1 义时生成
    { "sentence":"She has an interest in music.", "answer":"兴趣", "options":["兴趣","利息"] },
    { "sentence":"a 5% interest rate", "answer":"利息", "options":["兴趣","利息"] } ]
}
```
- `ensure_probes(db, word)`:命中缓存直接返回;否则 `complete_json(feature="vocab_probe", model=fast_model())` 生成 → 写回 `probes_json` → commit。(批量走 `backfill` + 预算熔断)

### 9.3 语境句来源(`pick_context`,个性化,决策①)
`pick_context(db, student_id, word_id) -> {text, source}`,逐级降级:
1. `vocab_wrong → wrong_record → 题干`中**含该词的那句**(学生自己的**错题原句**)→ source=`错题`
2. `vocab_question`(`q_scope=uploaded` 作业/试卷优先,后 `platform` 真题)→ 含该词的句子 → source=`作业/真题`
3. `VocabularyWord.examples[0].en` → source=`词典/教材例句`
4. `probes_json.cloze_fallback[0]` 或 LLM 现生成 i+1 句 → source=`AI`
> 长文本按句切分、取**含该词且整洁**的一句;取不到就降级下一来源。

### 9.4 一道接收 cloze 怎么拼(个性化语境 × 公共干扰项)
```
item.sentence = pick_context().text 中目标词 → "___"
item.options  = shuffle([目标词] + probes_json.distractors[:3])
item.answer   = 目标词
```
→ **题面来自学生自己的句子,选项=该词缓存的诊断干扰项**。这正是「题型公共、语境个性」的落地。

### 9.5 学一个词的流程(先语境后义)
1. 选词(现有词单调度)→ `ensure_probes(word)` + `pick_context(student, word)`
2. 呈现:**语境句**(目标词先挖空让学生猜 / 或高亮)→ 揭示 音·义·例 → **接收探针**(1 道语境 cloze;多义词再加 1 道 sense 辨析)
3. 提交 → `submit_probe` → `mastery_recep` 更新 → 过阈值(0.85)= 该词「可输入性理解」达成
4. 错 → 错词本 + 间隔重现排期(复用现有 SM-2 `next_review_at`/`is_wrong`)

### 9.6 判分 + 接收掌握度(BKT)
`submit_probe(db, student, word_id, kind, answer)`:
- 客观判分:`answer == 正确项`
- `mastery_recep = mastery_judge_service.bkt_update(prior_recep, correct)`(连对达标 / 蒙对不误判 / 答错回拉)
- `AnswerLog(feature="vocab_probe")` + 错→`is_wrong=true`/`wrong_count++`/排复习
- 返回 `{correct, correct_answer, misconception, recep, recep_mastered: recep>=0.85}`

### 9.7 接口(R9.1)
- `GET  /vocab/{word_id}/probes` → `{context:{text,source}, probes:[{kind,prompt,options}], recep}`(不含答案)
- `POST /vocab/{word_id}/probe` `{kind,answer}` → `{correct,correct_answer,misconception,recep,recep_mastered}`
- `POST /admin/vocab/probe-backfill?limit&max_tokens_budget` → `{scanned,filled,stopped,spent_tokens}`(复用预算熔断+看板)

### 9.8 复用映射(几乎全搬长难句)
| 需求 | 复用件 |
|------|--------|
| 探针生成 | `llm_provider.complete_json` + `fast_model()`(分档/finish_reason 智能重试) |
| 接收掌握度 | `mastery_judge_service.bkt_update` |
| 用量/成本可观测 | `usage_log_service`(feature=`vocab_probe`)→ LLM 看板 |
| 批量+成本熔断 | `usage_log_service.budget` / `over_budget` |
| 错词/复习排期 | 现有 `VocabularyLearning` SM-2 + 错词本 |

### 9.9 R9.1 验收
- **个性化语境**:有 `vocab_question/wrong` 的词,cloze 题面取自学生真实句(source 正确)。
- **诊断干扰项**:选形近词→返回对应错因。
- **recep BKT**:连对 N 次跨 0.85 判「可输入性理解」;蒙对一次不误判;答错回拉。
- **多义词**出 sense 辨析题。
- **缓存复用**:第二次学同词不再调 LLM;backfill 预算熔断生效;用量入看板(feature=vocab_probe)。
