## 一、背景与目标

产品方向从「AI 错题分析工具（V1）」转向「按教材打包的结构化知识库 + 题库 SaaS（V2）」。M1 是 V2 的数据地基，目标是：

1. 建立教材-学期-知识点数据模型
2. 会员体系从「按月」切换为「按学期购买」
3. 种子教材：**译林版小学5年级 + 初中7年级**（上/下各一学期）
4. 定价：后台可配置，初始值 Basic ¥39 / Pro ¥79 / ProMax ¥159（单位/学期）
5. 小程序首页改版为知识点宫格（M1 内容占位，M2 填充）

---

## 二、关键决策

| 决策 | 内容 |
|------|------|
| 教材版本 | 译林版（译林出版社，江苏/上海体系）|
| 知识点维度 | 6 维度：听力、词汇、语法、阅读、翻译、写作 |
| 版权隔离 | 真题（exam_papers/questions）内部存储，用户只见仿真题（simulated_questions）|
| 迁移策略 | 直接切换：旧 memberships 表保留结构不 DROP，新代码不读写，购买全走 purchased_semesters |
| 定价存储 | semester_pricing_config 表，平台超管可编辑，Redis 5 分钟缓存 |

## 三、数据库迁移（0022）

### 3.1 新增表

#### `knowledge_point_contents`
知识点六维度内容，M1 骨架为空，M2 AI 批量填充。

```sql
CREATE TABLE knowledge_point_contents (
  id                  uuid PRIMARY KEY,
  knowledge_point_id  uuid NOT NULL REFERENCES knowledge_points(id),
  dimension           varchar NOT NULL CHECK (dimension IN ('listening','vocabulary','grammar','reading','translation','writing')),
  content_md          text,
  audio_url           varchar,
  example_json        jsonb,
  status              varchar NOT NULL DEFAULT 'draft' CHECK (status IN ('draft','reviewing','published','retired')),
  generated_by        varchar CHECK (generated_by IN ('ai_full','ai_with_human_review')),
  reviewed_by         uuid REFERENCES users(id),
  reviewed_at         timestamptz,
  created_at          timestamptz NOT NULL DEFAULT now(),
  updated_at          timestamptz NOT NULL DEFAULT now()
);
```

#### `exam_papers`（内部，不对外）
平台管理员上传的真题试卷，永不暴露给学生端。

```sql
CREATE TABLE exam_papers (
  id                    uuid PRIMARY KEY,
  source                varchar NOT NULL DEFAULT 'official_seed' CHECK (source IN ('official_seed','teacher_upload')),
  uploader_id           uuid REFERENCES users(id),
  class_id              uuid REFERENCES classes(id),
  textbook_version      varchar NOT NULL,
  grade                 varchar NOT NULL,
  semester              varchar NOT NULL CHECK (semester IN ('上','下')),
  region                varchar,
  title                 varchar NOT NULL,
  paper_url             varchar,
  ocr_status            varchar NOT NULL DEFAULT 'pending',
  status                varchar NOT NULL DEFAULT 'draft' CHECK (status IN ('draft','published','retired')),
  internal_only         boolean NOT NULL DEFAULT true,  -- 永远为 true，API 层强制拦截
  created_at            timestamptz NOT NULL DEFAULT now(),
  updated_at            timestamptz NOT NULL DEFAULT now()
);
```

#### `exam_questions`（内部，不对外）

```sql
CREATE TABLE exam_questions (
  id            uuid PRIMARY KEY,
  paper_id      uuid NOT NULL REFERENCES exam_papers(id),
  question_no   varchar,
  question_type varchar NOT NULL CHECK (question_type IN ('单选','填空','完型','阅读','写作','听力','翻译')),
  stem          text,
  options       jsonb,
  answer        text,
  explanation   text,
  difficulty    smallint CHECK (difficulty BETWEEN 1 AND 5),
  created_at    timestamptz NOT NULL DEFAULT now()
);
```

#### `exam_question_knowledge_points`

```sql
CREATE TABLE exam_question_knowledge_points (
  exam_question_id    uuid NOT NULL REFERENCES exam_questions(id),
  knowledge_point_id  uuid NOT NULL REFERENCES knowledge_points(id),
  relevance           smallint NOT NULL DEFAULT 100 CHECK (relevance BETWEEN 0 AND 100),
  PRIMARY KEY (exam_question_id, knowledge_point_id)
);
```

#### `simulated_questions`（对外呈现的题库）
由 AI 基于真题改写生成，不暴露 source_exam_question_id 字段给外部 API。

```sql
CREATE TABLE simulated_questions (
  id                        uuid PRIMARY KEY,
  source_exam_question_id   uuid REFERENCES exam_questions(id),  -- 内部追溯，不对外
  knowledge_point_id        uuid NOT NULL REFERENCES knowledge_points(id),
  question_type             varchar NOT NULL,
  stem                      text,
  options                   jsonb,
  answer                    text,
  explanation               text,
  difficulty                smallint CHECK (difficulty BETWEEN 1 AND 5),
  generation_metadata       jsonb,
  status                    varchar NOT NULL DEFAULT 'draft' CHECK (status IN ('draft','reviewing','published','retired')),
  created_at                timestamptz NOT NULL DEFAULT now(),
  updated_at                timestamptz NOT NULL DEFAULT now()
);
```

#### `user_uploaded_papers`
学生上传的整卷（M4 主要使用，M1 建表备用）。

#### `user_paper_questions`

```sql
CREATE TABLE user_paper_questions (
```

#### `user_paper_question_knowledge_points`

```sql
CREATE TABLE user_paper_question_knowledge_points (
  user_paper_question_id  uuid NOT NULL REFERENCES user_paper_questions(id),
```

#### `purchased_semesters`（替代旧 memberships）

```sql
CREATE TABLE purchased_semesters (
  id                  uuid PRIMARY KEY,
  user_id             uuid NOT NULL REFERENCES users(id),
  textbook_version    varchar NOT NULL,
  grade               varchar NOT NULL,
  semester            varchar NOT NULL CHECK (semester IN ('上','下')),
  tier                varchar NOT NULL CHECK (tier IN ('basic','pro','promax')),
  semester_no         smallint NOT NULL DEFAULT 1,
  started_at          timestamptz NOT NULL,
  expires_at          timestamptz NOT NULL,  -- started_at + 6个月 × semester_count
  order_id            uuid REFERENCES orders(id),
  created_at          timestamptz NOT NULL DEFAULT now()
);
```

```sql
CREATE TABLE semester_pricing_config (
```

## 五、真题→仿真题流水线（M1 骨架，M2 完善）

```
管理员上传真题图片
        ↓
OCR 识别（复用现有阿里云/腾讯云流水线）
        ↓
AI 拆题（按题号识别题型，拆分 stem/options/answer）
        ↓
AI 知识点归类（每题关联 1-N 个 knowledge_points）
        ↓
写入 exam_questions + exam_question_knowledge_points（internal_only）
        ↓
AI 改写生成仿真题（simulated_questions，status='draft'）
        ↓
运营审核（status → 'published'）
        ↓
对外可用
```

**M1 阶段**：建表 + 流水线骨架（可跑通但无真实内容）。真实运营上传和 AI 改写在 M2 完善。

### 6.1 注册 onboarding 新增教材选择

`complete-profile` 页末尾加教材选择步骤：

```

                   ↓

```

### 6.2 首页改版：知识点宫格

```
┌────────────────────────────────┐
│  译林版 · 7年级上学期  [切换]   │
├────────────────────────────────┤
│  [未购] 解锁本学期 ¥39起·6个月 │  ← 已购用户不显示
├────────────────────────────────┤
│  Unit1 词汇   Unit1 语法        │
│  Unit1 阅读   Unit1 写作        │
│  Unit2 听力   Unit2 词汇  ...   │

├────────────────────────────────┤
│  错题本   学情   我的            │
└────────────────────────────────┘
```

知识点格点进去：M1 显示「内容即将上线」占位页；M2 填充真实内容。

### 6.3 购买流程

```
点「解锁本学期」
  → 选档位（Basic ¥39 / Pro ¥79 / ProMax ¥159）
  → 选学期数（1 / 2 / 3）
  → 显示总价（实时从 semester_pricing_config 取）
  → 微信支付
  → 回调 fulfill_semester_order
  → 返回首页，宫格解锁
```

### 6.4 Admin 后台：定价管理页

位置：平台超管 admin web → 系统配置 → 学期定价

| Basic | 39 | 编辑 |
| Pro | 79 | 编辑 |

修改后实时生效（清 Redis 缓存），下次购买请求即取新价格。
