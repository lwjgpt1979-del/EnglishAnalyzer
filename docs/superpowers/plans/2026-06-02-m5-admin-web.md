# M5 运营 Web 后台（脚手架 + 管理员登录 + 三审核/配置页）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现。Steps 用 checkbox (`- [ ]`) 跟踪。

**Goal:** 起一个独立的 Vue3 + Element Plus 运营 Web 后台，对接已就绪的 admin API（D-095 仿真题审核 / D-096 内容审核编辑 / D-097 定价配置），并补齐当前缺失的**管理员账号密码登录**（后端发 JWT），让运营无需碰 SQL 即可审核内容、改价。

**Architecture:**
- **后端**：管理员 = `role=platform_admin` 的 `users` 行。新增 nullable `username`(unique) + `password_hash` 两列（迁移 0015），合成 `openid="admin:{username}"` 满足 NOT NULL/unique 约束。新增 `POST /api/v1/admin/auth/login {username,password}` → bcrypt 校验 → 复用 `create_access_token(user_id, role)` 发 JWT。密码由运维通过 `scripts/create_admin.py` 初始化（从环境变量读明文 → bcrypt 落库；Claude 全程不接触明文密码）。
- **前端**：新建 `frontend/admin/`（Vite + Vue3 + TS + Element Plus + Pinia + Vue Router + axios）。登录页拿 token 存 localStorage；axios 拦截器注入 `Authorization: Bearer`，401 跳登录。三个业务页对接现有 admin API。dev 用 Vite proxy 把 `/api` 转后端。
- **零改动**：现有小程序、wx-login、所有现有 admin API 端点均不动。

**Tech Stack:** 后端 FastAPI + SQLAlchemy async + passlib[bcrypt]；前端 Vue3 + Element Plus + Vite + Pinia + Vue Router + axios + TypeScript。

**安全约束（贯穿全程）：** ① Claude 绝不读取/打印/提交明文密码或 JWT 密钥；② 管理员密码由用户自己经 `create_admin.py`（读环境变量）初始化；③ `frontend/admin/.env*` 不进 git（加 .gitignore）；④ admin API 全部经 `require_role("platform_admin")`，前端只是壳。

```python
from __future__ import annotations
import uuid
from passlib.context import CryptContext
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession
from app.models.d1_users import User

_pwd = CryptContext(schemes=["bcrypt"], deprecated="auto")

def hash_password(raw: str) -> str:
    return _pwd.hash(raw)

async def create_admin(db: AsyncSession, *, username: str, password: str) -> User:
    """创建/重置一个 platform_admin 账号（username 唯一，openid 合成占位）。"""
    existing = (await db.execute(select(User).where(User.username == username))).scalar_one_or_none()
    if existing is not None:
        existing.password_hash = hash_password(password)
        existing.role = "platform_admin"
        return existing
    user = User(
        id=uuid.uuid4(),
        openid=f"admin:{username}",      # 满足 NOT NULL/unique；admin 不走微信
        username=username,
        password_hash=hash_password(password),
        role="platform_admin",
    )
    db.add(user)
    return user

async def authenticate(db: AsyncSession, *, username: str, password: str) -> User | None:
    user = (await db.execute(select(User).where(User.username == username))).scalar_one_or_none()
    if user is None or not user.password_hash:
        return None
    if str(user.role) != "platform_admin":
        return None
    if not _pwd.verify(password, user.password_hash):
        return None
    return user
```

> 已核（d1_users.py）：`users` 表唯一无默认值的 NOT NULL 列就是 `openid` 与 `role`，上面 `create_admin` 已都设；其余列（is_active/created_at/profile_completed/is_anonymized/updated_at）均有 server_default，合规字段（birth_year/agreement_version 等）均 nullable。故无需额外补字段，admin 账号不参与 C 端合规流程。

```python
# schema
class AdminLoginRequest(BaseModel):
    username: str = Field(..., min_length=1)
    password: str = Field(..., min_length=1)

# admin.py 端点（无需 AdminDep；这是登录入口）
# 复用 auth.py 同款：from app.core.security import create_access_token, create_refresh_token
# TokenResponse{access_token, refresh_token, token_type="bearer"}（schemas/auth.py 已核）
@router.post("/auth/login", response_model=BaseResponse[TokenResponse])
async def admin_login(body: AdminLoginRequest, db: DbDep):
    user = await admin_auth_service.authenticate(db, username=body.username, password=body.password)
    if user is None:
        raise AppError(code=401, message="用户名或密码错误")
    return make_ok(TokenResponse(
        access_token=create_access_token(str(user.id), str(user.role)),
        refresh_token=create_refresh_token(str(user.id)),
    ))
```

> `TokenResponse` / `create_access_token` / `create_refresh_token` 与 `auth.py::wx_login` 完全一致，已核对，无需新增。`AdminLoginRequest` 可放 `schemas/auth.py`。
