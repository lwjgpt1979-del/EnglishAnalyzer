# R6 技术方案 · 资源层补全(讲解/视频/例句/范文/思维导图挂 knowledge_nodes)

> 依据:[重构-KP优先-需求分析.md](重构-KP优先-需求分析.md) 体系⑤ + 路线图 R6;承接 R0(`knowledge_nodes`)、R1(`unit_node`)。
> 原则:**新建通用 `node_resource` 表挂 `knowledge_nodes`**,承载多资源类型;旧 `knowledge_point_contents`(六维度讲解挂旧 KP)**保留不动、不桥接**(继续供现有学生前台)。

---

## 0. 现状关键事实(已核实)
- `KnowledgePointContent`(d11)= KP×六维度讲解(listening/vocabulary/grammar/reading/translation/writing),挂**旧** `knowledge_points`,UNIQUE(kp_id, dimension),有 content_md/audio_url/example_json/status/generated_by/reviewed_*;完整 生成(persist_unit)→审核(/admin/contents)→发布→学生读(/curriculum/.../contents) 链。
- **无** 视频/例句库/写作范文/思维导图 表。讲解音频靠 tts_service 手工填。
- 讲解资源**完全未接** `knowledge_nodes`。

---

## 1. R6 范围【决策后】
1. **新建 `node_resource`**(挂 `knowledge_nodes`,通用资源表):`resource_type ∈ {lecture, video, example, essay, mindmap}`;lecture 带 dimension(六维度);承载 content_md / 媒体 url / resource_json。
2. **审核/生成/读取**:新建 node_resource service(create/审核/编辑/学生读)+ admin API + 学生读 API(按 node)。
3. **后台资源管理页**(frontend/admin):多类型资源 新增/审核/发布。
4. **旧 `knowledge_point_contents` 不动、不桥接**(继续供现有前台);新资源走新表。

---

## 2. 新增 / 改动

### 2.1 `node_resource` 表(d19_node_resource.py + 迁移 m88)
| 列 | 说明 |
|---|---|
| id PK | |
| node_id → knowledge_nodes | |
| resource_type varchar(16) | lecture\|video\|example\|essay\|mindmap |
| dimension varchar(16) null | 仅 lecture:listening\|vocabulary\|grammar\|reading\|translation\|writing |
| title varchar null | 资源标题(视频/范文/思维导图名)|
| content_md text null | 讲解/范文正文 |
| media_url varchar null | 视频/音频/思维导图图 直链 |
| resource_json jsonb null | 例句数组 / 思维导图树 |
| status varchar(12) | draft\|reviewing\|published\|retired |
| generated_by varchar(16) | ai_full\|ai_with_human_review\|manual\|imported |
| sort_order int / reviewed_by / reviewed_at / created_at / updated_at | |
- **UNIQUE(node_id, resource_type, dimension)**:lecture 每维度一条(dimension 非空);其它类型 dimension=null → PG NULL 互异 → 可多条。

### 2.2 服务 `node_resource_service.py`(新)
- `upsert_lecture(node_id, dimension, content_md, ...)` / `add_resource(node_id, type, title, ...)`。
- `list_for_review(status, node_id, type)` / `review(id, approve, reviewer)` / `update(id, ...)`。
- `list_published(node_id, type=None)`:学生读(只 published)。

### 2.3 Admin API + 学生读 API
- admin(AdminDep):`GET /admin/node-resources`(过滤 type/status/node)、`POST /admin/node-resources`(新增)、`POST {id}/review`、`PUT {id}`。
- 学生(get_current_user):`GET /node-resources?node_id=&type=`(只 published)。

### 2.4 后台资源管理页(frontend/admin)
`NodeResources.vue`:按 node + 类型 列资源 / 新增(讲解/视频/例句/范文/思维导图)/ 审核发布。

---

## 3. 决策点【✅ 已定 2026-06-18】
- **R6-A = 新建通用 `node_resource` 表**(挂 knowledge_nodes,resource_type 多类型)。
- **R6-B = 旧六维度讲解不桥接**(`knowledge_point_contents` 保留供现有前台;新资源走新表)。
- **R6-C = API + 后台资源管理页 都做**。

---

## 4. 分步实施(每步可验收、可独立提交)
- **R6.1** `node_resource` 模型 + 迁移 m88 + schema 测试(lecture 每维度唯一 / 其它多条)。
- **R6.2** `node_resource_service`(upsert_lecture / add_resource / 审核 / list_published)+ 单测。
- **R6.3** admin API(列表/新增/审核/编辑)+ 学生读 API + HTTP 测试(含非超管 403 / 学生只见 published)。

## 5. 验收
- node 可挂 lecture(六维度)/video/example/essay/mindmap 多类型资源;lecture 每维度一条。
- 资源 draft→审核→published;学生按 node 只读 published。
- 后台资源管理页可用。
- 旧 `knowledge_point_contents`/讲解前台/审核不受影响;全量回归绿(7 个既有 .env/陈旧失败无关,见 [[test-env-gotchas]])。
