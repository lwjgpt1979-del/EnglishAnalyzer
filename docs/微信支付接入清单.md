# 微信支付接入清单

> 代码侧的微信支付 v3（JSAPI 下单 / 支付参数签名 / 退款 / 回调验签解密）已就绪，
> 且支持多收款主体（个体/公司/子公司）。本清单是**你/运维需要做的配置**。
> 安全规范：**密钥不写进代码或数据库**，仅写入服务器环境变量；我（助手）不代填密钥。

## 一、前置：申请资质（你做）

1. **微信支付商户号**：pay.weixin.qq.com 申请（需营业执照主体；个体工商户可申请）。拿到 **商户号 mchid**。
2. **小程序与商户号绑定**：mp.weixin.qq.com → 微信支付 → 关联商户号（appid ↔ mchid）。
3. **API v3 密钥**：商户平台 → 账户中心 → API 安全 → 设置 **APIv3 密钥**（32 位）。
4. **API 证书（商户私钥）**：商户平台下载 `apiclient_key.pem`（私钥）+ 记录 **证书序列号**。
5. **平台证书（微信公钥）**：用官方工具/接口获取「微信支付平台证书」，导出其**公钥 PEM**（回调验签用）。

## 二、后台配置收款主体（admin「🏦 收款主体」页）

为每个营业执照主体建一条收款主体，填**非密**字段：
- name、subject_type（个体/公司/子公司）、provider=`wechat`
- config（JSON）：`{"mch_id":"商户号","cert_serial":"证书序列号","app_id":"小程序appid"}`
- secret_alias：给该主体起个英文别名，如 `company_main`（密钥按此别名注入 env）
- 子公司主体：填「关联分公司ID」；并在分公司城市归属里配好城市 → 订单按学生城市路由到该主体
- 设默认：当前对外收款的主体点「设默认」（新订单走它；老订单仍走其原主体退款）

## 三、录入密钥（推荐：后台 UI 加密存库，不改服务器）

**只需在服务器配一个主密钥**（一次性，永久不动）：
```
FIELD_ENCRYPTION_KEY=<openssl rand -base64 32 生成>
```
然后在 admin「🏦 收款主体」→ 对应主体「密钥」按钮，**粘贴**以下三项（加密存库，明文不回显、接口不回传）：
- `WECHAT_PRIVATE_KEY_PEM`（API证书私钥 apiclient_key.pem 内容）
- `WECHAT_API_KEY_V3`（32 位 APIv3 密钥）
- `WECHAT_PLATFORM_PUBLIC_KEY_PEM`（微信支付公钥 pub_key.pem 内容）

> 加公司 / 加支付宝 / 加子公司 = 后台新增主体 + 录入密钥即可，**无需改服务器、无需重启**。
> 列表「密钥就绪」变绿即配置完成。

**兼容回退（可选）**：也支持把密钥放 env `PAY__<secret_alias>__<KEY>`；默认个体主体别名 `legacy_wechat`，env 缺失时回退旧的 `WECHAT_PAY_*` 单商户配置。优先级：库密文 > env 别名 > legacy settings。

## 四、开关与回调地址

- `WECHAT_PAY_SKIP_SIG_VERIFY=false`（**生产必须 false**，启用回调验签）
- `WECHAT_PAY_REFUND_ENABLED=true`（允许真实退款；false=只记账 dev-mock）
- **回调地址**（商户平台无需单独配，下单时由后端按主体下发 notify_url）：
  - 默认主体：`https://api.goodgrammar.top/api/v1/webhooks/wx-pay`
  - 非默认主体：`https://api.goodgrammar.top/api/v1/webhooks/wx-pay/{收款主体id}`
  - 两者都需在小程序后台「服务器域名」白名单内（同域名即可）。

## 五、自检

1. 后台收款主体列表「密钥就绪」显示**已就绪**（绿色）= env 密钥被正确读到。
2. 真机小程序下单 → 唤起微信支付 → 支付成功后回调 `/wx-pay`：
   - 后端日志无「验签失败/解密失败」；订单状态变 `paid`；会员激活。
3. 退款：后台「💸 退款/申诉审核」通过一笔 → 微信商户平台能看到退款记录。

## 六、代码侧已完成（无需你改）

- JSAPI 下单、支付参数签名、退款 v3：`services/wechat_pay_service.py`（按收款主体凭证）
- 回调**验签**（平台公钥 RSA-SHA256）+ AES-GCM 解密：`verify_and_decrypt_callback`
- 多主体回调路由：`/webhooks/wx-pay` 与 `/webhooks/wx-pay/{account_id}`
- 凭证按 secret_alias 从 env 读取：`services/payment_account_service.py`
- 单测覆盖验签正确/篡改/缺头：`tests/api/test_wechat_pay_callback.py`

## 七、后续（非本次）

- 平台证书自动轮换（/v3/certificates 拉取并热更新）：当前用固定平台公钥 PEM，证书轮换时需更新 env。
