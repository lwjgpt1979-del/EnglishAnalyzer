# 表意配图 · 让抽象词也出合理图 · 最终方案

> 状态:**设计待评审,未开发**。综合近期讨论(think 卡"生成中"、C/D/E/F 分层、全项目口径、规则可改)收敛成一套最终方案。目标:**抽象词也能出"合理"图**(不出乱码/词不达意图),**纯功能词优雅无图不卡**,并把规则从"纸面要求"变成"代码结构强制"、覆盖全项目(含未来考点/例句配图)。

## 0. 现状(只读已核实)

- **全项目唯一出图管线** = `vocab_media_service._gen_images_for` → `vocab_media_provider`(腾讯混元 t2i/i2i/i2v)。考点/例句配图**代码里没有**(kp_lecture 仅一个可选 `media_url` 字段,无 AI 出图)。
- **可画性闸门**:`_ai_visual_brief` 让快档 LLM 出「场景 scene + 自评 drawable」;`_gen_images_for` 里 `drawable < 0.45(_DRAWABLE_MIN)` → 中止出图、保持 `draft`。
- **质量兜底**:`doubao_vision_service` 图文一致复核(verify_min 0.6),已是共享,能刷掉坏图。
- **brief 指令后台可编辑**(`get/set_brief_prompt`,配图页)。

## 1. 病因(三个)

1. **硬闸门把"难直接画"当成"不可画"** —— `think/happy/because` 被自评低分一律拒,其实它们**抽象但可具象化**。
2. **造场景只有一招(直接画这个词)** —— 没有"例句/隐喻/人物"等把抽象义落成具体场景的策略。
3. **`media_status` 只有 draft/published,"确定无图"与"本次失败待重试"不分** —— 功能词永远停在 `draft` → 前端("查看即生成"乐观占位)**永久转"生成中"**(就是 think 那个现象)。

## 2. 总纲:三层架构 + 三态结局 + 共享强制入口

```
任何"表意出图"调用方(单词 / 未来考点·例句 …)
        │ 统一调用(唯一入口)
        ▼
  visual_brief_service.plan_visual(新建·共享)
   ├ L1 路由:term → concrete | abstract_depictable | function_only
   └ L2 造场景:按子类型 例句C / 隐喻D / 人物E → 一句可画 scene
        │ 返回 {category, subtype, scene, drawable, gate_ok, reason}
        ▼
   ┌────────── 三态结局 ──────────┐
   │ ① 出图 → t2i → L3复核 → 过=有图 published / 不过→②
   │ ② 复核连续不过 → 降级无图词义卡(media_status=text_only,不再重试)
   │ ③ 场景生成/服务失败 → draft(下次查看即生成重试)
   │   注:任何词(含虚词)都先尝试出图,不预判②;②只由复核兜底触发
   └──────────────────────────────┘
   L3 兜底(现成不动):doubao_vision 图文一致复核 + 降级
```

要点:**"确定无图"和"待重试"分开**(治 think 卡生成中);**造场景多策略**(救回抽象词);**闸门抽成共享入口**(全项目 + 未来统一)。

## 3. L1 路由 + L2 场景策略(升级 brief,一次调用出全)

升级 brief 的 meta-prompt,让一次快档调用**同时**返回分类与场景:

```
plan_visual 返回:
  category : concrete             具象(apple/run)→ 直接画
             abstract_depictable  抽象可具象化(think/happy/because)→ 走 L2
             function_in_context  功能/虚词(the/of/and)→ 用「含该词的例句场景」画(C 兜底,不放弃)
  subtype  : emotion|mental|metaphor|general
  scene    : 一句可画英文场景(已按策略造好;任何词都产出)
  drawable : 0-1 参考分(不再当硬闸门,喂 L3 复核当难度提示)
  gate_ok  : 有词意 ∧ 有 scene(几乎总为真;唯一 false = 场景生成彻底失败)
  reason   : 降级/失败原因
```

**决策①(定):不预判"不出图"** —— 任何词都尝试造场景出图:具象直接画、抽象走 L2、**连冠词/介词/连接词也用"含该词的例句场景"去画**(如 `of`→"a cup of water" 场景、`because`→"下雨所以打伞")。**无图只发生在:场景生成失败(→③draft 重试)或 L3 复核连续不过(→②降级 text_only)**,不再有"预先判死不画"的类别。

L2 策略 = 同一 meta-prompt 内的分支指令(不写多条代码路径):
- **E 人物**(emotion/mental):画人物表情+姿态传达心理状态,可加想法气泡。`think`→托腮沉思+气泡。
- **D 隐喻**(metaphor):用公认视觉隐喻。`freedom`→挣脱的鸟;`because`→多米诺因果。
- **C 例句**(general + 功能/虚词·**通用兜底**):先想一句 CEFR-A2 例句,再画那句场景。最稳、天然可画,**虚词也靠它出图**。

## 4. 三态 `media_status` + 前端不卡(治"卡生成中")

**决策②(定):扩 `media_status` 枚举**(不新增列,不搅动现有 draft/published 审核语义):
- `published` —— 有合格图,可见。
- `text_only` —— **新增枚举值**:已解决的**无图词义卡**(复核连续不过而降级),可见、**不再重试**。
- `draft` —— 生成中 / 场景或服务失败待重试(下次查看即生成再试)。

**前端**:`published` / `text_only` 都当正常卡渲染(`text_only` = 无图词义卡:词+释义+发音),**从"生成中"集合移除**;仅 `draft` 显示"生成中"。修 `genWords`:ensure 返回"已解决(published 或 text_only)"即清除。→ 抽象/虚词不再空转。

> 收编之前 A/B 的"卡生成中"UX:根因就是缺 `text_only` 这个"完成·无图"枚举值。
> 注:`text_only` 现在只由 **L3 复核降级** 触发(不预判虚词),但枚举值仍需要,用于"确定无图、别再转圈"。

## 5. 共享强制入口 `visual_brief_service`

- 把现内嵌于 `vocab_media_service` 的 `_ai_visual_brief` + 闸门判定**搬到新服务** `visual_brief_service`,入参通用化(`term/meaning/kind/pos/context`,不只 word)。
- `vocab_media_service._gen_images_for` 改为**调 `plan_visual`**;`i2i` 重刷劣质配图也走同闸门;`i2v` 在已过闸门的图之后,不加闸门。
- **未来任何表意出图(考点/例句配图)必须调 `plan_visual`** —— 规则从此结构强制。

## 6. L3 质量兜底(现成,略强化)

- `doubao_vision` 图文一致复核(verify_min)保留;**抽象词坏图风险高 → 可略提 `verify_candidates` / `verify_min`**。
- 复核不过 → 降级 `text_only`(**绝不硬塞坏图**,与铁律一致)。这是"放宽前置闸门"的安全垫。

## 7. 规则修订(CLAUDE.md,病根之一在规则实现口径)

现规则(第 67 行「生成配图/媒体:双闸门…失败即止不出兜底图」)**精神对(防裸词/坏图),但实现被做成"可画性硬拒",过度拒抽象词**。修订(不推翻、只精化):

1. **场景闸门增"先造场景再决定"**:任何词(**含冠词/介词/连接词**)都**必须先经 L2(例句/隐喻/人物;虚词走例句场景)尝试造出可画场景**;拿到合格 scene 就出图,**不再按"可画性自评低分"预先拒、不预判某类词不可画**。即"缺场景就止"改为"**穷尽造场景策略后仍无场景才止**"。
2. **明确三态结局**:「有图 → `published`」/「L3 复核连续不过 → 降级 `text_only`(可见·不再重试)」/「场景或服务失败 → `draft` 重试」。
3. **新增唯一入口条款**:凡表意出图**必须经 `visual_brief_service.plan_visual`**,不允许各处内嵌 brief/闸门。
4. **联动"查看即生成"规则**:功能词的无图卡也算"已生成内容",消费点不得空转"生成中"。

## 8. 成本 / 风险 / 回归

- **成本**:brief 仍 1 次快档调用(不增付费点);但**抽象词现在会真去 t2i**(以前跳过)= 新增出图开销;功能词零开销。
- **风险**:放宽前置闸门 → 坏图风险↑,由 **L3 复核**兜(复核不过即降级 text_only)。
- **回归词表**(每类代表词验:路由对不对 / 出图或降级 / status 对不对 / 前端不卡):
  - 具象 apple、run;情感 happy、worry;心理 think、decide;隐喻 freedom、time;功能 the、of、because、never。

- **P1**(主体):抽 `visual_brief_service`(L1+L2-C+闸门)+ vocab 改调用 + `text_only` 三态 + 前端不卡 + i2i 接入 + **CLAUDE.md 规则修订**。→ 抽象词救回、功能词不卡、全项目统一。
