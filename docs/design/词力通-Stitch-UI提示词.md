# 词力通 · Google Stitch UI 提示词

> 给 [Google Stitch](https://stitch.withgoogle.com) 生成「词力通」(背单词模块)移动端 UI 的提示词集。
> 用法:**一屏一条**生成;每条都先粘「风格基线」再接「屏幕提示词」,保证整套风格统一。
> 进阶:先把现有「首页」截图传给 Stitch 当风格参考,一致性最好。出图后用追加指令微调。

---

## 0. 风格基线(每条提示词都先粘这段)

```
为一款面向中国中小学生的英语学习微信小程序设计移动端界面(竖屏,375pt 宽)。
设计语言:主色 天空蓝 #3d8bf5;浅灰背景 #f4f6fa;白色圆角卡片(圆角 12-16px)+ 轻柔阴影;
图标全部用「线性描边」风格(Feather / Lucide 那种,2px 描边、圆角端点),禁止用 emoji 当图标;
中文用 PingFang SC,字号清晰、留白充足;整体气质:干净、友好、鼓励性,适合 12-15 岁学生,不要花哨。
界面文案用简体中文。
```

## 1. 词力通主页(今日任务)

```
设计「词力通」背单词主页。从上到下:
① 顶部:问候语 + 今日学习进度环(今日 12 / 20 词);右上角「设置」线性图标。
② 7 天打卡日历条:显示连续打卡天数;已打卡日点亮天空蓝,灰色日期标注「可补签」。
③ 主操作大卡:「开始今日学习」实心天空蓝按钮;卡内小标签显示本组规则(每组 5 词 · 每组 2 遍)。
④ 两个入口卡并排:「错词本」(右上角待复习数量角标)、「学情报表」，图标符合主色调。
⑤ 右下角「+ 添加生词」悬浮按钮。
卡片化布局,数据用大号数字突出,鼓励性但克制。
```

## 2. 学词 + 答题卡(核心流程,一次聚焦一张卡)

```
设计单词学习卡片页。顶部一条细进度条 +「本组 第 2/5 词」。
中间一张大白卡:正方形大图+中号英文单词 + 音标 + 中文释义;单词右侧三个线性小图标:发音、跟读;
卡片下方两个可折叠区:「例句」「短语」。
卡片下面是答题区:一道选择题,4 个选项为大号圆角按钮(纵向排列);
答对 → 选项变#4DB2FF +「答对了!」;答错 → #FFF6EA标出 + 显示「正确答案」+「下一题」按钮。
整体沉浸、干净,一屏只做一件事。
```

## 3. 跟读练习(录音 + 发音评分)

```
设计「跟读练习」页:
上方卡片展示要朗读的中号英文单词（+正方形大图）,旁边「示范」按钮(播放标准发音);
中间一个大号麦克风录音按钮(点击开始 / 停止;录音时麦克风周围有声波动画);
录完后:「我的录音」播放条 +「重跟」按钮;
原单词和我的单词录音合并一起播放的按钮[发音对比]
下方发音评分卡:平均分用环形进度(大号数字)+「需加强」的音/词标签列表。
配色鼓励性,主色天空蓝。
```

```

顶部总览卡:已掌握词数 / 待复习 / 正确率(三个大号数字并排);
一张近 7 / 30 天学习趋势折线图(可切换);
```

## 6. 错词本

```
设计「错词本」列表页:
顶部筛选标签(待复习 / 全部)+ 待复习数量;
每个错词一张卡:单词 + 中文释义 + 错误次数标签 + 发音线性图标 +「移出」;

```

## 7. 学习设置(弹层 / 抽屉)

```
设计「学习设置」底部抽屉:
三个数字步进设置:每组词数、每组遍数、错几次带入下组;
下方一段灰色说明:「每组学几个词、重复学几遍由你定;学完可一直『再来一组』。一个词在本组
错够『带入下组』的次数,就会自动滚入下一组继续考察(不超过遍数)。」

```

## 8. 添加生词(弹层)

```
设计「添加生词」底部弹层:
搜索输入框(英文单词)+ 下方匹配到的词条卡(单词 + 音标 + 释义);
一段灰色提示:「仅支持词典已收录的词;加入后会进入你的词单,之后学习会学到。」
底部「加入词单」主色按钮。
```

## 写提示词的要点

- **一屏一条**:别让 Stitch 一次画完所有屏,分开生成更可控、风格更稳。
- **从上到下列板块**:用 ①②③ 把布局顺序讲清,比堆形容词有效。
- **给真实文案 / 数据**:写「今日 12/20 词」「每组 5 词 · 2 遍」这种具体内容,出图更像成品。
- **复用风格基线**:八条都带同一段基线,整套才统一(尤其"线性图标、禁 emoji、主色 #3d8bf5")。
- **传参考图**:把现有首页截图喂给 Stitch 当风格锚点。
- **迭代追加**:出图后微调,如「答题选项改成 2×2 网格」「卡片圆角再大一点」「图标描边再细一点」。
- 若 Stitch 对中文排版处理不佳,可改用英文写「布局结构」、保留界面文案为中文示例词。
