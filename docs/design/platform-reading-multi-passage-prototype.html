方案 A · 篇章子 Tab（推荐）

  • ✓ 左文右题始终 1:1 对照，语篇完整可读
  • ✓ 按 block_id 自动拆 Passage A/B/C/D，待处理数 per 篇
  • ✓ 「本篇章 AI / 批量解析」粒度正确，不重跑其它篇
  • ✓ 表格列：rc 技能 + evidence + 状态，对齐科学解析
  • △ 需多点一次篇章 Tab（4 篇卷可接受）
实现：阅读 kind=reading 时，sec.groups 每个有 block_id 的 group → 一个篇章 Tab；无 block 的独立题归「其它」。

方案 B · 纵向卡片

  • ✓ 一屏纵览 4 篇进度，不用切 Tab
  • ✓ 适合篇章少(2–3 篇)的卷
  • ✗ 4+ 篇时滚动很长，左文右题区域被压扁
  • ✗ evidence 高亮跨卡片难联动
备选：篇章 ≤3 时可作折叠卡片；默认仍用方案 A。
