事件与冒泡

  1. 词 / 句片段：@tap.stop，不触发原文整块折叠。
  2. segTap：若 word_idx != null → 开词卡并 return；否则若 sentence_idx != null → 开句卡。
  3. 句首图标：与该句同一 sentence_idx，行为等同点句。
  4. 证据句高亮（解析「回原文定位」）：蓝底叠加在词/句之上，不改变点击目标。
  5. 底部「本篇精讲」面板：列表点词仍开 WordCard；列表点句可直达完整精讲（现有行为可保留）。
