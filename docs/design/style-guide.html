5 · 落地建议 Next Steps

1. 定稿本规范 → 把 :root 这套 token 转成小程序 uni.scss / 全局 CSS 变量（rpx 版）。
2. 抽公共组件：<AppButton>（黄底深字主按钮）、<AppCard>（大圆角）、<AppTag>（pill）、<EmptyState>。
3. 回填翻新：把现有 9 个页面的蓝色主调 #1677ff 全量替换为黄油黄体系，圆角加大，按钮改黄底深字。
4. 真机验证：微信开发者工具跑一遍确认 rpx 渲染。
＊关键差异：原 v0.1 是科技蓝（#1677ff），v0.2 改为黄油相机的奶油黄 + 深字 + 超大圆角 + 暖色调。这是一次主色与气质的整体切换。
＊提示：黄油相机是相机/生活方式 App，奶油黄活泼友好；用在英语错题工具上，做题区建议保持高对比（深字/白底）以护眼专注，黄色主要用于按钮、激活、强调，避免大面积铺黄。
