# 长难句 · Google Stitch UI 提示词

> 给 [Google Stitch](https://stitch.withgoogle.com) 生成「长难句学习」移动端 UI 的提示词集。
> 用法:**一屏一条**生成;每条先粘「风格基线」再接「屏幕提示词」。先把现有「首页」截图传给 Stitch 当风格锚点最佳。
> 长难句特有视觉:**英文句用衬线体(Georgia/Times)**,中文 PingFang SC;**句子按成分切段,每段彩色虚线下划线 + 段首词下方一个同色数字圆点**。

---

## 0. 风格基线(每条提示词都先粘这段)

```
为一款面向中国中小学生的英语学习微信小程序设计移动端界面(竖屏,375pt 宽)。
设计语言:主色 天空蓝 #3d8bf5;浅灰背景 #f4f6fa;白色圆角卡片(圆角 14-24px)+ 轻柔阴影;
图标全部用「线性描边」风格(Feather / Lucide 那种,2px 描边、圆角端点),禁止用 emoji 当图标;
英文句子用衬线体(Georgia / Times),中文用 PingFang SC;字号清晰、留白充足;
整体气质:干净、专注、鼓励性,适合 12-15 岁学生,不要花哨。界面文案用简体中文。
```

## 1. 长难句学习主页(读句态)

```
设计「长难句学习」主页(读句状态)。从上到下:
① 顶部进度:「今日学会 3 句 · 为你匹配难度 ~62」+ 细进度条;右上角「连续 5 天」打卡胶囊。
② 句子卡头:左侧翻页(‹ 第 2 句 ›);中间「真题」「复习」小标签;右侧难度环(圆环数字 83 + 「难度·高」,
   高=红 / 中=橙 / 低=绿)。
③ 脚手架引导条(浅底色卡):图标 +「进阶·划结构」+ 一句提示「先自己划主干和从句,再点显示结构核对」。
   三档配色:入门·看懂=浅绿、进阶·划结构=浅蓝、挑战·输出=浅橙。
④ 原句区(核心视觉):一段长英文句,按语法成分切成多段,每段一种颜色的虚线下划线,
   每段首词正下方一个同色小数字圆点(1、2、3…);英文用衬线体、行高大、可读性强。
⑤ 颜色图例:一行小圆点 + 成分名(主句主语 / 谓语 / 定语从句 / 状语从句 / 介词短语…)。
⑥ 工具栏:一排线性图标按钮 —— 听 / A− / A+ / 护眼 / 翻译 / 收藏 / 更多。
⑦ 底部一条主色 CTA:「检测理解 · 过关才算学会这句」(脑/靶心线性图标)。
专注阅读、彩色成分标注是主角。
```

## 2. 理解检测(双探针答题)

```
设计「理解检测」答题面板(接在句子卡下方)。两道题纵向排列:
题1「剥掉修饰和从句,这句的主干(主谓核心)是?」——4 个选项为句子片段按钮(纵向),选中描天空蓝边。
题2「下面哪句最准确地表达了原句的意思?」——4 个中文释义选项按钮。
下面一行可选自评:「顺便说下感受(可选):太简单 / 刚好 / 有点难」小胶囊(可不选)。
底部「提交检测」主色按钮(未答满时置灰)。干净、聚焦,一次答两题。
```

## 3. 检测结果(通过 / 未过 + 诊断)

```
设计「理解检测结果」卡片,两种状态:
通过:浅绿卡 + 对勾图标 +「理解通过 · 这句算学会了」;下面两条:「✓ 点主干 · 答对」「✓ 句意理解 · 答对」。
未过:浅橙卡 + 警告图标 +「还没全懂 · 已加入复习,稍后再练」;每条探针:✗ 点主干 → 显示「正确答案:…」
   + 一行诊断错因(如「这是从句,不是主干——主句才是句子骨架」);答对的探针显示 ✓。
错因文字用暖橙色,克制不刺眼。
```

## 4. 短翻译产出(维度 rubric 评分)

```
设计「进阶·试译这句」短翻译产出卡:
顶部入口按钮「进阶 · 试译这句,检验输出」(浅橙、钢笔线性图标);点开后:
多行文本输入框(占位:用中文写出这句的意思,尽量把主干、逻辑关系、修饰都译到位)+「提交翻译」按钮。
评分结果卡:左上总分(如 8/8,达标绿、不达标橙)+「输出达标 ✓」标签 +「重译」;
下面 4 行维度,每行:维度名(命题准确 / 逻辑关系 / 修饰归属 / 主干完整)+ 右侧 2 个圆点表示得分(0-2)+
一句中文点评;底部「总评」一句改进建议。
```

## 5. 迁移挑战(同结构新句 + 结论)

```
设计「迁移挑战」卡:
头部「迁移挑战」标签 + 与原句共享的句法结构标签(如「并列结构」「定语从句」);
展示一句结构相同、内容全新的英文句(衬线体);下面是同样的双探针(点主干 + 释义单选)+「提交迁移检测」。
结论卡两态:
成功:浅绿 + 奖杯图标 +「迁移成功 · 真的掌握了这个句法!」+ 一句「在新句里也认出了『并列结构』,
   说明学的是结构不是这道题」;
未过:浅橙 + 刷新图标 +「像是记住了原题 · 换句就卡住了」+「这个句法点还没真正掌握,已加入复习」。
```

## 6. 结构解析(主干树 + 多 Tab)

```
设计长难句「结构解析」区:
顶部分段控件 Tab:句子结构 / 句子成分 / 重点词汇 / 语法点。
「句子结构」:顶部一张主色浅底「主干」卡,向下箭头,展开成 2 列「从句/修饰」小卡(每张:彩色序号 +
   成分类型 + 该片段原文),呈紧凑树状。
「句子成分」:主语/谓语/宾语 等成分逐行(chip 标签 + 内容)。
「重点词汇」:词条卡(单词 + 词性 + 释义)。
「语法点」:按语法族上色的浅底卡(语法点名 + 一句讲解)。
下方「结构解析」卡:句型标签 + 逐条解析时间线(彩色序号圆点连成竖线 + 文字)+「小结」。
信息密集但分层清晰、配色与原句成分色呼应。
```

## 7. 底部栏 + 「更多」弹层 + 打卡日历

```
设计三个附属件(同一风格):
① 底部固定栏:左「生词本」、中间主色大按钮「再学一句」、右「错题本」(均线性图标 + 文字)。
② 「更多」底部弹层:列表项 —— 显示/隐藏原句结构、复制原句、难度说明、查看语法点详解;底部「取消」。
③ 打卡日历弹层:连续天数 / 历史最高 / 本月打卡 三个数据 + 月历网格(打卡日点亮天空蓝、今日描金边)+
   底部「立即打卡」按钮。
```

## 写提示词的要点

- **一屏一条**:核心是「主页读句态 / 检测 / 结果 / 翻译 / 迁移 / 解析」,分开生成最稳。
- **强调彩色成分标注**:长难句的灵魂是"按成分切段 + 彩色虚线 + 段首序号",务必在提示词里讲清。
- **英文衬线体**:明确"英文句用 Georgia/Times 衬线体",和中文区分,更像专业阅读材料。
- **给真实文案**:把「今日学会 3 句 ~62」「进阶·划结构」「迁移成功」等真实标签写进去,出图更像成品。
- **复用风格基线 + 传首页截图**:整套一致性最好。
- **迭代追加**:如「难度环换成更细的描边」「脚手架条颜色再淡一点」「成分配色用更柔和的马卡龙色」。
- 若 Stitch 中文排版不佳,可用英文写「布局结构」、界面文案保留中文示例。
