推荐 · 路径 1

确认时程序挂词

  • 不改 AI prompt；采纳瞬间从 options+answer 抽词
  • 零额外 LLM；可批回填历史已解析题
  • 弹窗多一行「主考/干扰 chip」只读预览
优点：省钱稳。缺点：复杂选项/双空需规则拆点，难例人工改。
路径 2

解析弹窗内审词

  • 建议阶段就出挂词草案，运营可改 chip
  • 确认时连 analysis + 词边一起落库
优点：可控。缺点：多一步交互；批量采纳要带编辑态。
路径 3

解析 LLM 兼出词

  • analysis JSON 增 correct_words / distractor_words
  • 适合非标选项（短语嵌套、双空）
优点：理解力强。缺点：贵；与程序结果要对齐、要缓存。
