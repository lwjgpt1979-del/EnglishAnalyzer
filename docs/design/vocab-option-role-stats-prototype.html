词 × 正确项 / 干扰项 · 统计与反查原题

目标：按单词统计「在多少道独立词项单选真题里当过主考 / 干扰」， 并能分页拉出对应原题（real，非仿真）。 在此基础上，中考卷限定下支持按省或市两个维度聚合/筛选。 明确不要：阅读理解短文选择题、缺词填空、变词/动词填空。

1. 现成数据（不用新表也能原型）

表用途
vocab_question PK (word_id, q_scope, question_id)； link_kind ∈ correct | distractor | occur； option_key = A–D（可空）
platform_question 原题；type='real'；meta.analysis.kind 区分题型解析形态； exam_type（中考|高考|普通）、region_code（省2位/市4位，与 region 表同源）
region + region_service 地区唯一真源；region_breakdowns(codes) 批量解析省/市名； 筛选前缀 region_code LIKE '{code}%'（与 kp_exam_stats 一致）
vocabulary_words 词文本、释义等

已有 GET /admin/vocab/{word_id}/platform-questions?role=correct|distractor， 但未过滤「独立词项单选」池，需加 pool 参数（见下）。

2. 统计池定义：standalone_word_mcq

纳入（单独逻辑的原题 · 四选一 · 词/短语作选项）：

  • meta.analysis.kind = 'grammar_mc'（语法/词法/句法单选，已确认解析）
  • 或兜底：question_type='单选' + 段名不含 阅读/完形/缺词/短文/动词/词形/词汇运用 + 题干能拆出 ≥2 个 A–D 选项

排除：

类型判定
阅读理解kind=reading / rc_code / 段名含「阅读」
完形（短文多选）kind=cloze / 段名含「完形|完型」/ block_id+完形段
缺词填空kind=passage_fill / 段名含「缺词|短文填空」
变词/动词填空kind=word_fill / 题干 (work) 所给词 / 段名含「动词填空|词形|词汇运用」
仿真题platform_question.type != 'real'
vocab_question→ JOIN platform_question→ filter pool→ GROUP BY word_id, link_kind

范围：仅 exam_type='中考' + 池 standalone_word_mcq。

地区桶（与 region 码前缀一致，复用 region_service.region_breakdowns 展示名）：

维度分组键说明
region_level=province LEFT(pq.region_code, 2) 一省一行；如 32 → 江苏省
region_level=city LEFT(pq.region_code, 4) 一市一行；如 3202 → 无锡市；region_code 不足 4 位的不进市维度（或单列「仅省级码」）

6. 核心 SQL 原型（standalone_word_mcq + 中考地区）

6.1 池过滤（SQL 片段，落 service 时可改 Python 判定复用 option_vocab_service）

-- 简化版：kind=grammar_mc 的真题
SELECT vq.word_id, vq.link_kind, COUNT(DISTINCT vq.question_id) AS n
FROM vocab_question vq
JOIN platform_question pq ON pq.id = vq.question_id
WHERE vq.q_scope = 'platform'
  AND vq.link_kind IN ('correct', 'distractor')
  AND pq.type = 'real'
  AND pq.meta->'analysis'->>'kind' = 'grammar_mc'
GROUP BY vq.word_id, vq.link_kind;

6.2 一词两列透视（全国 · 不限地区）

SELECT w.word,
  COUNT(DISTINCT vq.question_id) FILTER (WHERE vq.link_kind = 'correct') AS correct_n,
  COUNT(DISTINCT vq.question_id) FILTER (WHERE vq.link_kind = 'distractor') AS distractor_n
FROM vocabulary_words w
JOIN vocab_question vq ON vq.word_id = w.id AND vq.q_scope = 'platform'
JOIN platform_question pq ON pq.id = vq.question_id AND pq.type = 'real'
  AND pq.meta->'analysis'->>'kind' = 'grammar_mc'
GROUP BY w.id, w.word
ORDER BY correct_n DESC
LIMIT 50;

6.3 中考 · 词 × 省

SELECT w.id AS word_id, w.word,
  LEFT(pq.region_code, 2) AS region_code,
  COUNT(DISTINCT vq.question_id) FILTER (WHERE vq.link_kind = 'correct') AS correct_n,
  COUNT(DISTINCT vq.question_id) FILTER (WHERE vq.link_kind = 'distractor') AS distractor_n
FROM vocabulary_words w
JOIN vocab_question vq ON vq.word_id = w.id AND vq.q_scope = 'platform'
  AND vq.link_kind IN ('correct', 'distractor')
JOIN platform_question pq ON pq.id = vq.question_id
  AND pq.type = 'real'
  AND pq.exam_type = '中考'
  AND pq.meta->'analysis'->>'kind' = 'grammar_mc'
  AND pq.region_code IS NOT NULL AND LENGTH(pq.region_code) >= 2
GROUP BY w.id, w.word, LEFT(pq.region_code, 2)
ORDER BY correct_n DESC;

6.4 中考 · 各省汇总（group_by=region）

SELECT LEFT(pq.region_code, 2) AS region_code,
  COUNT(DISTINCT pq.id) AS question_count,
  COUNT(DISTINCT vq.word_id) AS word_count,
  COUNT(DISTINCT (vq.word_id, vq.question_id))
    FILTER (WHERE vq.link_kind = 'correct') AS correct_link_count,
  COUNT(DISTINCT (vq.word_id, vq.question_id))
    FILTER (WHERE vq.link_kind = 'distractor') AS distractor_link_count
FROM platform_question pq
JOIN vocab_question vq ON vq.question_id = pq.id AND vq.q_scope = 'platform'
  AND vq.link_kind IN ('correct', 'distractor')
WHERE pq.type = 'real'
  AND pq.exam_type = '中考'
  AND pq.meta->'analysis'->>'kind' = 'grammar_mc'
  AND pq.region_code IS NOT NULL AND LENGTH(pq.region_code) >= 2
GROUP BY LEFT(pq.region_code, 2)
ORDER BY question_count DESC;

市维度把 LEFT(..., 2) 改为 LEFT(..., 4) 且 LENGTH >= 4；region_code=32 筛选加 pq.region_code LIKE '32%'。

8. 验收标准

  • 词 Can：correct_count 只含语法单选原题，不含阅读/完形/动词填空
  • 反查列表 analysis_kind 均为 grammar_mc（或池兜底判定通过）
  • 未挂边 / 未确认解析的题不进统计（无 vocab_question 边即无数据）
  • 分页：列表页强制 skip/limit + total（admin 铁律）
  • 中考 + region_level=province：无锡卷题计入 32 江苏省，不与其它省混
  • 选 region_code=32®ion_level=city：仅江苏省下各市分行，点市反查仅该市原题
  • 地区名来自 region 表 / region_breakdowns，非写死清单
