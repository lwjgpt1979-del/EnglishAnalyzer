相对现网的变化

  • 重新生成 / LLM 解析单元 → 统一为 课程内容提取（可选自 PDF / 粘贴 / 合并）。
  • 关联知识图谱 → 独立阶段或「挂靠台」Tab：默认「只看未挂」+「一键关联未挂点」+ 逐点挂靠/新建。
  • 左侧：单元 PDF | 粘贴原文 仅作对照与提取源；粘贴区有 保存原文（落库本单元，下次打开仍在）。
  • 空态：无结果时大按钮引导提取，而不是灰掉的「重新生成」。
  • 付费：提取按输入内容 md5 暂存；同输入不二次调 LLM。
