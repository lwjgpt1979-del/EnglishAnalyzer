正确答案 C · 春雨润万物 → everything
复合不定代词
空缺指「万物/一切」时用物称全称。
✅ 正确 C · everything
everything = 每件事、一切（物）。春雨润万物 → 选 everything。
❌ 你选 B · nothing
nothing = 没有什么。否定语义，与句意相反。
⚪ 干扰 A · nobody / D · everybody
人称复合词；空缺非人称，形近干扰。
