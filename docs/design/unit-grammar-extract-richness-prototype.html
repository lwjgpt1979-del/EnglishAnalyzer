单元解析
方案 语法点粒度 例句 挂图谱 贴近人工清单 成本 / 风险
A 粗点多句（推荐） 维持粗点（be=1） 每点 3–8 句原句编号 不变 中（多句齐） 低；改 prompt + 解析
D 双层 粗点挂靠 + 细目折叠 细目下多句 仍按粗点挂 高 中；需存 sub_points JSON
F 两段式 粗点（现有） 第二段只补编号句 不变 中 可控；两段各缓存
G 先对图谱 对齐 cf/jf 节点名 节点下挂多句 自动命中率更高 中（受目录约束） 中；要喂节点目录
E 句优先 一句多标签 句全覆盖 需聚合后再挂 高（覆盖面） 高；模型与 UI 大改
B 细拆子类 肯定/否定/疑问… 每子类多句 点爆炸，难对齐 最高 改挂负担大
C 另导出 挂靠流不动 独立 Markdown/表 零影响 可做得很细 多一次付费调用+缓存
现状 粗点 每点 1 句 简单 低 已上线
