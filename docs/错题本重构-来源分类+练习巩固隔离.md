# 错题本重构 · 来源分类 + 练习巩固隔离(实施计划)

> 定稿于 2026-07-21。目标:错题本按**来源**分类,类目内**聚合折叠 + 待复习优先**收敛规模;
> 三处系统练习(考点扩展测试 / 仿真练习)产生的错误作为**练习衍生**薄弱项**打标隔离**,不污染真实错题、不产生循环。

## 定稿决策

- **顶层 tab(选 a·纯按来源)**:作业错题(`source_label='作业'`)/ 真题错题(`整卷`)/ 长难句错题(`长难句`)/ 平台错题(`平台`)/ **练习巩固**(`is_original=false`,灰隔离)。
  - **词汇 / 语法降为副筛选**(`kp_kind` 筛选 chip),不再占顶层 tab(避免与来源轴重叠)。
- **类目内**:顶部「今日待复习 N 题」优先条(SM-2 到期,复用 `review-queue`)+ **A 按考点 / B 按批次** 双视图折叠卡(进度即底色)。
- **隔离位**:复用 `wrong_record.is_original`。真实错题 `true`(不变);练习衍生 `false`。
- **练习衍生写入**:
  - ①错题网·考点扩展测试 + ③词力通·考点扩展测试(题带 `dimension`)→ 按 **(word, dim)** upsert 一条 `is_original=false`。
  - ②练同类·仿真题 → 维持 `record_practice_result` 推**父错题** SM-2,**不新建**。
- **决策 1(question_id/q_scope)= b**:`question_id = uuidv5(NS, f"{word_id}:{dim}")` 确定性派生,`q_scope='kp'`;命中现有唯一键 `(student_id, q_scope, question_id)` 天然去重。
- **决策 2(粒度)= 词·维**:`kp_name="tradition·近义"`,存 `dim` + `vocab_word_id`。
- **决策 3(掌握清除)= 连对 N=2**:`practice_streak` 计数,重练答对 +1,≥2 → `status=mastered` 移出「练习巩固」。
- **防循环铁律**:练习衍生项「重练」= 重出该 (word,dim) 一套题;结果只 upsert 回**同一行**,永不生成新的练习衍生错题。

## A. 数据模型 / 迁移(m194,无新表)

`wrong_record` 复用,新增 2 列:

| 列 | 类型 | 用途 |
|---|---|---|
| `dim` | varchar(16) null | 练习衍生的考点维 key(synonym/collocation…);真实错题为空 |
| `practice_streak` | smallint default 0 | 连对计数,达 2 → 掌握清除 |

复用已存在:`is_original`、`vocab_word_id`、`source_label`、`node_id`/`kp_name`、`source_id`、SM-2 全套(`review_count`/`next_review_at`/`practice_count`)。`q_scope='kp'` / `source_label='练习巩固'` 均在现有 varchar 长度内。

## B. 后端 service(`wrong_center_service.py`)

1. `record_kp_practice(student, word_id, sense_id, dim, dim_label, word, correct, missed_q)`:
   - `question_id = uuidv5(word_id, dim)`,`q_scope='kp'`。错 → upsert(`is_original=false`, `dim`, `vocab_word_id`, `kp_kind='vocab'`, `kp_name`, `source_label='练习巩固'`, streak=0, 冗余题面);对 → 命中 open 记录则 streak+1,≥2 置 mastered。
2. **②仿真不变**。
3. `list_center` 扩展 `source_label` + `is_original` 过滤;`lifecycle_counts` 加 source 作用域。
4. 聚合查询:`group_by_kp(student, source_label)`(A 视图)、`group_by_batch(student, source_label)`(B 视图)、`list_practice_consolidation(student)`(练习巩固 tab)。
5. **待复习条**:复用 `wrong_review_service.get_due_queue` / `review-queue`。

## C. 后端 API(`wrong_center.py` / `vocabulary.py`)

- 扩展 `GET /wrong-center/list`:params `source_label`、`is_original`、`view=kp|batch`。
- 新增 `GET /wrong-center/grouped`(kp/batch 聚合)、`GET /wrong-center/consolidation`(练习巩固)。
- 新增 `POST /vocab/kp-practice/record` `{word_id, sense_id, results:[{dim, correct}]}`(①③ 逐题结果回传;判分在前端,这里只记薄弱/连对)。**P3 落地**。
