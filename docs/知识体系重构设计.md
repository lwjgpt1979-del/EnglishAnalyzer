## 一、需求分析

### 1.1 一句话目标

建立**一套以"知识点"为骨架的英语学习知识体系**（覆盖小/初/高，贯通听/说/读/写），所有学习资产（教材、真题、仿真题、学生平时卷、错题、词与短语）都**引用**到这套骨架上、并可**拓展**骨架；每个学生在骨架上拥有**自己的个人知识体系投影**（命中的点 + 来源 + 掌握度）。

### 1.2 核心概念（统一词汇）

| 概念 | 定义 |
|------|------|
| **知识骨架（Backbone）** | 平台统一、唯一的知识点图（树/网）。维度：学段(小初高)×技能(听说读写)×类别(语法/词汇/…)。是一切的锚点。 |
| **知识点节点（KP）** | 骨架上的一个点，如"过去完成时""定语从句""话题作文-环保"。 |
| **引用（Reference）** | 某资产命中骨架已有节点（建立 资产→KP 边）。 |
| **拓展（Extension）** | 资产触发骨架**新增**节点（受控扩张骨架，挂回正确学段/技能/教材）。 |
| **资产（Asset）** | 教材讲解、真题题、仿真题、学生上传卷的题、错题、词/短语。 |
| **个人知识体系（Student Projection）** | 某学生在骨架上的子图：命中的 KP + 来源标签 + 掌握度 + 关联资产。 |

### 1.3 角色

学生（C 端核心）、老师/亲人（查看学生投影）、平台运营（维护骨架与教材内容）、机构（机构学生聚合）。

### 1.4 功能需求（FR）

**A. 知识骨架**
- FR-A1 骨架以学段(小初高)×技能(听/说/读/写)×类别 组织；节点可成树（parent_id）。
- FR-A2 节点带：名称、学段适用、教材适用、技能轴、讲解内容（×维度）。
- FR-A3 骨架唯一、去重：同一知识点不得产生多个并行节点（杜绝当前 `auto_*` 碎片）。

**B. 引用与拓展（资产 → 骨架）**
- FR-B1 **教材**：所选教材的单元/内容引用 KP；教材未覆盖但相关的点为"教材拓展"。
- FR-B2 **真题**：上传真题卷 → 拆题 → 每题引用 KP；真题可"拓展"骨架。
- FR-B3 **真题→仿真题**：基于真题按 KP 生成仿真题，构成**该 KP 的仿真题库**。
- FR-B4 **学生平时卷**：学生上传自己做过的整卷 → 拆题 → 引用/拓展 KP。
- FR-B5 **错题**：学生错题（来自整卷或单题）引用/拓展 KP。
- FR-B6 **词力通**：词与短语作为骨架的"词汇子层"，挂到 KP / 教材单元。

**C. 错题练习对标仿真题（本轮新增核心规则）**
- FR-C1 **错题的练习/拓展题，统一对标"该错题所属 KP 下、由真题生成的仿真题"**——即错题复习练同类 = 从该 KP 的**仿真题库**取题，而非临时随机生成。
- FR-C2 若该 KP 仿真题库不足，则**按真题样式补充生成并入库**（生成物进同一仿真题库，供后续复用），保证"练的题"始终对标真题水准。
- FR-C3 错题练习作答计入该 KP 掌握度（与仿真练习同口径）。

**D. 学生个人知识体系**
- FR-D1 学生选教材 → 自动关联该教材覆盖的 KP，形成个人骨架初始投影。
- FR-D2 上传卷/错题/词汇学习 → 持续把命中 KP 并入个人投影（带来源标签）。
- FR-D3 提供"我的知识地图"：按 技能/学段/教材单元 浏览，弱点高亮，可下钻到来源资产 + 练同类。
- FR-D4 掌握度按 KP 聚合（已有台账），趋势可查。

### 1.5 关键业务规则

- BR-1 **唯一骨架**：所有"挂 KP"入口（教材/真题/学生卷/错题/仿真题/词汇）必须经**同一知识点解析服务**（受控分类：优先命中候选 KP，未命中才受控拓展），不得各自 `get_or_create` 裸建。
- BR-2 **错题练习 = KP 仿真题库**（FR-C1/C2）：错题 → KP → 仿真题库取题；不足则补生成入库。
- BR-3 **个人投影只读叠加于骨架**：学生数据不污染骨架；骨架是平台资产，拓展需受控（自动补元数据 + 可后台复核）。
- BR-4 **词汇子层归一**：词/短语既是词力通学习对象，也是知识体系节点的一部分（按 KP/单元归属）。

### 1.6 非功能需求
- 一致性优先：宁可受控拓展也不放任碎片化。
- 兼容现状：复用现有 `knowledge_points / knowledge_point_contents / exam_* / simulated_questions / user_paper_* / vocabulary_*`；**未上线，可改表**。
- 可演进：骨架支持运营后台增删点/改技能轴，不发版。

### 1.7 与现状差距 & 重构范围

| 蓝图要素 | 现状 | 重构动作 |
|---|---|---|
| 唯一骨架 | `knowledge_points`（树/年级/教材/类别）已在 | **加技能轴(听说读写)**；**统一解析、消灭 auto_ 碎片** |
| 每点讲解 | `knowledge_point_contents`（6维度） | 复用 |
| 教材→KP | curriculum + applicable_textbooks | 显式"引用/拓展"语义 |
| 真题→KP | `exam_question_knowledge_points` 已在 | 复用 |
| 真题→仿真题库(按KP) | `simulated_questions`(knowledge_point_id) 已在 | 作为**唯一仿真题库**，错题练习对标它 |
| 学生卷→KP | `user_paper_question_knowledge_points`(D-165打通) | 走统一解析 |
| 错题→KP | `wrong_questions` 未挂 KP | **补挂 KP** |
| 错题练习 | 临时 LLM 生成(`practice_records`) | **改为对标 KP 仿真题库**(FR-C) |
| 词汇子层 | `vocabulary_words`+`curriculum_words` | 并入图谱（挂 KP/单元） |
| 个人知识图谱 | `student_kp_mastery`+快照，来源散落 | **新增统一"学生知识图谱"服务/视图** |

## 二、数据模型

> 原则：能复用就复用；只在缺口处加列/加表。未上线，迁移可一刀到位。

### 2.1 骨架层（knowledge_points 强化）

`knowledge_points`（既有）新增/明确：
- `skill`（技能轴枚举：`listening|speaking|reading|writing`，可空=跨技能）— **新增**。
- 既有 `category`（grammar/vocabulary/reading/writing/listening）保留为"题材/类别"；**补 speaking**。
- `stage`（学段：`primary|junior|senior`）— 由 applicable_grades 推导或新增显式列，便于按小初高聚合。
- `status`（active/archived）+ `origin`（`seed|textbook|exam|extension`）标记节点来源（拓展可复核）。
- 既有 `parent_id` 树、`applicable_grades/textbooks` 保留。

`knowledge_point_contents`（既有）：每 KP×维度讲解，复用。

`knowledge_point_aliases`（**新增**，可选但推荐）：`(kp_id, alias)`——同义词/别名表，受控分类按别名命中，根治"换个说法就新建"。

### 2.2 资产层（均已存在，确认挂 KP）

- 教材：`curriculum_units` / `knowledge_point_contents`（教材讲解即 KP 内容）。
- 真题：`exam_papers` / `exam_questions` / `exam_question_knowledge_points`（真题题↔KP）。
- 仿真题库：`simulated_questions`（`knowledge_point_id`，`source_exam_question_id` 溯源真题）= **该 KP 的唯一仿真题库**。
- 学生卷：`user_uploaded_papers` / `user_paper_questions` / `user_paper_question_knowledge_points`。
- 错题：`wrong_questions` — **加 `knowledge_point_id`（或复用关联表）补挂 KP**。
- 词汇子层：`vocabulary_words` + `curriculum_words`（单元↔词）；**新增 `knowledge_point_words(kp_id, word_id)`** 让词/短语挂 KP（可选）。

### 2.3 引用/拓展边（统一语义）

所有 `资产→KP` 边统一为"引用"；当解析判定"骨架无此点"→ 受控新建 KP（`origin=extension`）再建边 = "拓展"。
边表已分散存在（exam_question_knowledge_points / user_paper_question_knowledge_points / wrong_questions.kp_id）。**不强行合表**，但**统一经解析服务写入**。

### 2.4 学生投影层（既有 + 视图）

- `student_kp_mastery`（既有：student×KP 掌握度）+ `kp_mastery_snapshots`（趋势）。
- **新增来源标签**：mastery 行加 `sources`（JSONB：textbook/exam/paper/wrong/vocab 命中来源集合），或由各资产边实时聚合（推荐实时聚合，不冗余）。
- 个人知识图谱 = 实时聚合查询（见架构 3.4），不一定新建表。

### 2.5 仿真题库与错题练习（FR-C 落地）

- `simulated_questions` 作为**唯一练习题源**（按 KP）。
- `sim_practice_records` 记录作答（既有，已挂 KP）。
- 错题练同类：`错题→kp_id→simulated_questions(该KP)` 取题；不足时调生成器**按真题样式生成并 INSERT 进 simulated_questions**（进库复用），再返回。
- **逐步弃用** `practice_records` 的临时生成路径（或令其也写入 simulated_questions 统一库）。

## 三、架构设计

### 3.1 分层

```
骨架层  knowledge_points(+skill/stage/alias)  ← 唯一锚点
  ▲ 统一写入（受控分类）
解析层  kp_resolver_service  ← 所有挂KP入口的唯一通道
  ▲
资产层  教材 / 真题 / 仿真题库 / 学生卷 / 错题 / 词汇   （各自→KP 边）
  ▲
投影层  student_knowledge_service  ← 学生知识图谱（聚合骨架子图+来源+掌握度）
  ▲
应用层  我的知识地图 / 错题练同类(对标仿真题) / 教材讲解下钻 / 词力通
```

### 3.2 知识点解析服务 `kp_resolver_service`（地基，BR-1）

唯一入口 `resolve(db, *, name|stem, grade, textbook, skill) -> KnowledgePoint`：
1. 取该学段/教材下**候选 KP 清单**（名称+别名）。
2. AI **受控分类**：让模型从候选清单中选（命中=引用）；附"以上都不是"选项。
3. 命中 → 返回该 KP；未命中 → **受控拓展**：新建 KP（自动补 stage/skill/textbook，`origin=extension`，可后台复核），写别名。
4. 替换现有 `kp_classifier`(自由命名) + `get_or_create_knowledge_point`(裸建)。所有入口（整卷/错题/真题/仿真题）改调它。

### 3.3 错题→对标仿真题链路（FR-C）

`wrong_practice_service.similar_for_wrong(db, *, wrong_ref, student)`：
1. 解析错题 KP（wrong_questions.kp_id / user_paper_question→KP）。
2. 查 `simulated_questions` where kp_id=该KP，取 N 题（去重已练）。
3. 不足 N → 调仿真题生成器（基于该 KP 关联真题样式）补足并入库。
4. 返回题目（不含答案）；作答经 `sim_practice_records` 计入掌握度。
统一替代整卷的 `practice_for_question`（D-165 临时生成）与 practice 的 ad-hoc 生成。

### 3.4 学生知识图谱服务 `student_knowledge_service`

`graph(db, student)`：聚合
- 命中 KP 集合（来自 教材关联 ∪ 学生卷 ∪ 错题 ∪ 词汇）。
- 每 KP：来源标签、掌握度、关联资产计数（真题题/错题/仿真练习/词）。
- 按 技能/学段/教材单元 分组；弱点（掌握度<阈值或有错题）高亮。
接口：`GET /me/knowledge-graph`（学生）、机构/老师看学生版。

### 3.5 API 草案（增量）

- `GET /me/knowledge-graph?group_by=skill|stage|unit`
- `GET /me/knowledge-points/{kp_id}`（下钻：讲解+我的真题题+错题+仿真练习+词）
- `POST /wrong/{ref}/similar`（错题练同类，对标仿真题库）
- 运营：`GET/PUT /admin/knowledge-points`（骨架增删/技能轴/复核拓展节点）

### 3.6 分期实施（依赖顺序）

- **P0 骨架对齐（地基）**：KP 加 skill/stage(+speaking)；`kp_resolver_service` 受控分类 + 别名；统一所有挂 KP 入口；wrong_questions 补挂 KP。
- **P1 错题对标仿真题**：`wrong_practice_service` 走 KP 仿真题库（不足补生成入库）；替换 D-165 临时生成。
- **P2 学生知识图谱**：`student_knowledge_service` + 我的知识地图前端。
- **P3 KP 下钻 + 词汇子层并入**：节点下钻五类资产；`knowledge_point_words` 挂词。
- **P4 运营骨架后台**：拓展节点复核、技能轴/别名维护。

> 每期可独立验收；P0 是其余各期的前提（与上轮结论一致）。
