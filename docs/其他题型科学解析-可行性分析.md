# 其他题型科学解析(单选/填空/听力)—— 可行性分析

> 承《书面表达-科学解析与写作引导》《AI整卷匹配-分题型科学解析》。铁律沿用:
> **AI 只出建议,人工确认唯一写库;考点码确认时自动挂 KP 边;运营可配置值读后台。**

## 0. 结论先行

1. **框架已完全就位、可复用**:解析对象 `meta.analysis` + `suggest_analysis` 分发 + `confirm_analysis`
   (校验/force/审计/**确认即挂 KP 边**)+ 反向生成 + 学生练评。每个新题型**只需三样**:
   ①解析对象形态 ②校验器 ③LLM 提示词 + 一个分发分支。
2. **考点树现成**:词法 `cf-*`(148)、句法 `jf-*`(182)、听力 `lt-*`(22)——语法/听力题的
   "科学解析"= 挂对应叶子 + 该题构念说明,**词法/句法就是教材那套逻辑**(铁律原话)。
3. **按体量与难度分三期**:语法单选(~2457,最大最简)→ 填空类(动词填空/词汇运用/短文填空/完成句子)
   → 听力(需音频/听力材料,最复杂,单列)。

## 2. 各题型「解析对象」怎么科学拆(每种一条构念主轴)

沿用"载体(区分度≈0)vs 构念(真被测)"的思路,每型给最小充分的解析对象:

### 2.1 语法单选(词法/句法)—— P1,先做
- **构念主轴**:考点 `kp_codes`(cf-*/jf-*,教材同逻辑)。**载体 = 句子话题(区分度≈0)**。
- 解析对象:`{kind:"grammar_mc", kp_codes:[cf/jf], answer_reason(为何选它:命中哪条语法规则),
  distractors:{A:{meaning:该选项形态/义, why_wrong:违反哪条规则/时态不符/搭配错}}}`。
- **干扰项复用完形那套「原义+干扰机制」**(形态本身合法、错在与本句语法/搭配冲突)——已建、直接用。
- 校验:kp_codes 非空且图谱存在(cf-/jf-)、每个非正确项 meaning+why_wrong 双全、answer_reason 非空。
  **无需原文子串**(单选自足,线索在本句)。

### 2.2 填空类 —— P2
- **动词填空**:`{kind:"verb_fill", form:"所需形式(过去式/现在分词/被动…)", kp_codes:[jf 时态语态/cf],
  clue:"定形线索(时间状语/主句时态/主谓一致)", answer_reason}`。
- **词汇运用/单词拼写**:`{kind:"word_fill", target:"目标词", change:"词形变化类型(名→形/加ing…)",
  kp_codes:[cf 构词], clue:"语境依据"}`。
- **短文填空**:近完型 → **直接复用完形双轴**(载体槽 + 线索类型 + 线索句),差别是开放填空无选项。
- **完成句子/翻译/句型转换**:`{kind:"sentence", target_structure:"目标句型(强调/倒装/从句)",
  kp_codes:[jf], key_points:[采分点], answer}`。
- 校验:有原文/短文的(短文填空)线索句须原文子串(防幻觉);其余校验 kp_codes + 关键字段非空。

### 2.3 听力 —— P3,单列
- **构念**:听力技能 `lt-*`(细节定位/主旨/推断/数字信息…)。
- 解析对象:`{kind:"listening", lt_code, evidence:"听力材料中的定位句(需听力文本)", answer_reason, distractors}`。
- **前置依赖**:多数听力题库无听力材料文本(仅题干+选项)。需先补听力原文(OCR/人工/已有材料),
  否则 evidence 无从校验。故听力**单列专项**,不并入本期。

## 3. 复用矩阵(几乎零新基建)

| 能力 | 现状 | 新题型要做 |
|---|---|---|
| 解析对象 meta.analysis | ✅ 完型/阅读/写作 | 加各型字段 + `kind` |
| suggest 分发 | ✅ 三路 | 加分支(按 question_type/section 判型)|
| confirm 校验/force/审计/**挂KP边** | ✅ | 加各型 validator |
| 反向生成仿真 | ✅ 完型/阅读/写作 | 语法单选/填空走单题改写(继承考点+干扰机制)|
| 学生练评 + BKT | ✅ 写作 5 维;阅读表达简答 | 语法单选=客观题走既有判分闭环(选对/错)→ BKT |
| 干扰项「原义+干扰机制」 | ✅ 完型/阅读 | 语法单选直接复用 |

## 4. 分期(每片人工确认才写库)

- **P1 语法单选(词法/句法)** — 体量最大、最简、复用最多。解析对象+校验+分发+提示词 +(可选)反向生成。
  产物:对一道语法单选做「cf/jf 考点 + 选它的规则依据 + 干扰项原义+违规机制」,人工确认写库并自动挂 KP 边。
- **P2 填空类**(动词填空/词汇运用/短文填空/完成句子):按上面各自解析对象;短文填空复用完形双轴。
- **P3 听力**:先补听力材料文本(前置专项)→ lt-* 技能 + 定位句解析。

## 5. 风险

| 风险 | 对策 |
|---|---|
| 语法单选量大、人工确认瓶颈 | 复用「批量解析全段 + 一键采纳校验通过项」;cf/jf 候选按学段过滤 |
| 单选题目自足、无短文 → 无原文子串锚 | 校验不强制子串,改校验「kp_codes 命中 + 干扰机制双全」 |
| 听力缺材料文本 | 单列 P3,先补文本再解析 |
| 词形变化判定主观 | LLM 给 change 类型 + cf 考点,人工确认;错因分类留痕 |

## 6. 一句话

框架已备,新题型=「配一个解析对象 + 校验器 + 提示词 + 分发分支」。**先做语法单选(P1)**:
词法/句法考点(教材逻辑)+ 选项规则依据 + 干扰项原义&违规机制 → 人工确认 → 自动挂 cf/jf 考点边 →
仿真同考点改写 → 学生客观判分落 BKT。
