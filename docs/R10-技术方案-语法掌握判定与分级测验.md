# R10 技术方案 · 语法掌握判定与分级测验(词法/词组/句法:真会·蒙对·手抖可分 + 冷启动定级 + 纸质材料先验)

> 把「正确率」换成「**概率掌握(BKT) × 多维证据 × 防蒙题型 × 迁移 × 间隔保持**」,在 真会/蒙对/手抖/刷题过拟合 的噪声里,科学且可解释地判定一个语法知识点是否「基本学会」;并解决冷启动定级(基础未知)与纸质作业/试卷的利用。方法论沿用 R9(词力通可输入性理解),迁到语法 KP。

---

## 0. 现状关键事实(已核实)

- **BKT 已建好蒙/抖模型** —— `mastery_judge_service.py`:`L0=0.25`、`T=0.18`、`G=0.20`(蒙对率)、`S=0.10`(手滑率)、判掌握阈值 `0.95`。`bkt_update(prior, correct)` 连对快速逼近 1,答错按手滑率回拉。
- **语法 KP 树存在** —— `KnowledgePoint`(`parent_id` 层级、`category`、`applicable_grades`),经 `curriculum_units`(`textbook_version`/`grade`/`semester`/`unit_no`)+ `unit_knowledge_points` 可圈出「译林版 × 年级 × 学期」的语法点。**无显式先修 DAG**,用「树层级 + 单元先后顺序」作难度/先修近似。
- **纸质→数字化→KP 链路齐全** —— 整卷/错题拍照上传 → `ocr_service`/`doubao_vision_service` → 拆题(`real_extract_service`/`paper_split`)→ `kp_classifier_service` 映射 KP → `wrong_question_knowledge_points` / `student_kp_mastery`。
- **R9 机件可整套复用** —— `vocab_probe_service`(探针库 + 多维 + 迁移 + 成组防蒙 + 离线预生成钩子/cron)、`vocabulary_service.sm2`(间隔)、`student_kp_mastery`(掌握快照)。

## 1. 要解决的问题(操作化)

1. **判定**:某语法点是否「基本学会」——必须能区分 **真会 / 蒙对 / 手抖 / 刷题过拟合**。
2. **定级(冷启动)**:初二译林版学生进来,基础未知,如何用最少题快速定起点。
3. **纸质先验**:学习起点前做过的大量纸质作业/试卷,如何科学地当参考。

三者关系:**定级(粗、快、低置信)定起点 → 日常判定环(精、慢、高置信)坐实**;纸质材料是定级的第三路输入。

---

## 2. 核心原理:三支柱

| 支柱 | 作用 | 落点 |
|---|---|---|
| **概率掌握(BKT,含 G/S)** | 把"蒙对/手抖"建进模型,而非数正确率 | `mastery_judge_service.bkt_update` |
| **多维证据(识别/纠错/产出/迁移)** | 单一题型易蒙;跨题型 + 新语境取证 | 新 `grammar_probe_service`(仿 R9) |
| **时间保持(间隔复测)** | 破"刷同一套题过拟合";学会要扛过时间 | `vocabulary_service.sm2` |

## 3. 掌握判定(日常环)

### 3.1 四维证据(词法/词组/句法通用)

同一语法点跨四种题型取证,**各跑一条 BKT**:

| 维度 | 题型 | 验什么 | 防什么 |
|---|---|---|---|
| ① 识别 recognize | 选择正确形式 | 认得出 | 入门 |
| ② 纠错 detect | 找错 + 改对(改错题) | 能发现违例 | 比选择难蒙 |
| ③ 产出 produce | 填空 / 句子转换 / 造句 | **会用**(开放产出) | **几乎无法蒙** |
| ④ 迁移 transfer | **全新句子/语境**用同一规则 | 真懂规则、非背题 | **刷题过拟合** |

> 例「现在完成时」:能选 ✔ → 能挑出 `I have went` 的错并改对 ✔ → 能把给定句改写成完成时 ✔ → 在没见过的新句里正确使用 ✔。

### 3.2 BKT 如何天然分离 蒙/抖/真会

- **蒙对一次**:P 仅由 0.25 升到 ≈0.4,远不够阈值。
- **真会连对 3~4 次**:快速逼近 0.95 判掌握。
- **真会后手抖错一次**:仅由 0.96 回拉到 ≈0.8,再对即恢复 → 不冤枉。

### 3.3 防蒙题目工程

- **成组混合检测**(复用 R9.5 `group_recep`):一组句子共享选项库、答案逐句不同,"这题=A"的背题策略失效。
- **误区导向干扰项**:干扰项专打该语法点典型错误(三单漏 s、时态混用、语序…),选错即定位**具体误解**。
- **反应时 + 犹豫信号**(复用 `hesitant`):又快又对=流利;慢而对/自报犹豫 → 本次证据按蒙/抖侧打折。

### 3.4 「基本学会」判定门槛

```
标记 KP = mastered 需同时满足:
  P(掌握 | 纠错)   ≥ 0.95
  且 P(掌握 | 产出) ≥ 0.95
  且 ≥1 道迁移题(新语境)通过
  且 ≥1 次间隔复测通过(隔 ≥3 天的新题仍对)
  且 近期无"系统性错误"(区别于单次手抖)
```
(只过①识别**不算**学会。)

### 3.5 给学生的诚实标签(可解释、可申诉)

> 「现在完成时:你在 选择/改错/造句/新句 4 种场景连续答对,且隔 3 天复测仍对 → **基本掌握 ✓**」

展示**证据**而非黑箱百分比。

## 4. 分级测验(冷启动 placement)

### 4.1 定位

**快、粗、定起点**:用最少题给「译林初二(±前置)每个语法点」设**起始掌握先验**并圈薄弱区。**不判真会**(那是日常环)。产出标**低置信、待确认**。

### 4.2 题库圈定(译林初二 ± 前置)

| 段 | 来源 | 作用 |
|---|---|---|
| 前置 | 译林初一 + 小学核心语法点(`curriculum_units` grade<初二 → `unit_knowledge_points`) | 找地基洞 |
| 当前(主体) | 译林**初二**已学/在学单元语法点 | 定当前线 |
| 略超前 | 初二后续 1~2 单元 | 探天花板 |

(均按 `textbook_version=译林` 过滤。)

### 4.3 自适应路由(CAT)

1. 起点:初二当前进度线的中等难度点(难度阶梯 = 单元 `unit_no` 顺序 + KP 树深度)。
2. 答对 → 跳更深/更后;答错 → 退前置/更浅。
3. 每点连续 2~3 题定调,不靠单题。
4. 人均 15~25 题、10~15 分钟。

### 4.4 知识空间二分推断(进一步砍题)

- **过下游难点 → 上游基础推定为会**(跳过)。
- **基础点崩 → 其依赖点先不考**(必崩),直接标"从此处补"。
- 把"考试"变成在 KP 树上的**二分定位**,题量 O(KP) → O(log)。

### 4.5 BKT 暖启动

每次作答更新对应 KP 先验;结束时每点不再是默认 `L0=0.25`,而是测出来的起点:连对→0.6~0.8(疑似会,待确认);连错→0.1(薄弱);未考/推断→中性默认。写入 `student_kp_mastery`(标 `prior_source=placement`、低置信)。

### 4.6 控时 + 抑制蒙污染

- 题型:以 识别 + 纠错 为主求速度;**边界点补 1~2 道产出题**防高估。
- 反应时/犹豫打折。
- 先验**全部标"待确认"**,真假交日常环。

### 4.7 产出:语法掌握热力图

```
地基(初一/小学)  ●●●○●   ← 三单(○)优先补
初二上            ●●○○·    ← 时态过渡薄弱
初二下/超前        ··        ← 未学,留白
```
颜色=起始先验(已会/临界/薄弱/未学);一条"学习起点线";每点写好 BKT 初始先验 → 无缝接日常环。

## 5. 纸质作业/试卷作为先验(第三路输入)

### 5.1 核心:错题可信,对题不可信

纸质看不到过程(蒙/抄/批改对错/谁做的),**不能整体当掌握度**。但错题/对题信息价值不对称:

| | 信号 | 为什么 | 用法 |
|---|---|---|---|
| **做错的题** | **强(可信)** | 极少"不小心做错";即便手抖也值得查 | **拉低该 KP 先验** + 置顶进自适应首批探测 |
| **做对的题** | **弱(噪声大)** | 可能真会/蒙/抄/重做背下 | 只当"疑似会"候选,**标待验证,不加分** |

> **用错题"找洞",别用对题"发奖状"。**

### 5.2 可可靠榨取的 4 类信息

1. 错题 KP 分布 → 薄弱热区(最强)。
2. **错误内容 → 误区诊断**(最值钱:系统性错误 vs 偶发笔误;并喂给 3.3 的误区干扰项)。
3. 覆盖范围(学过/没碰过 → 留白≠洞)。
4. 量 + 新近度(近的/考试的权重高)。

### 5.3 接成 placement 第三路

- 错题 → KP 先验下调 + 置顶进 CAT 首批探测点(测验更快收敛)。
- 对题 → 先验**轻微**上调 + 打"待确认",placement/日常用迁移题坐实才真上调。
- 错误类型 → 写入该 KP "疑似误区"。

### 5.4 噪声护栏

- **来源可信度加权**:监考试卷 1.0 > 课堂作业 0.7 > 家庭作业 0.4(可抄)。
- **新近度衰减**(如半衰期 90 天)。
- OCR/KP 映射可人工纠错。
- **绝不跳过验证**:纸质只设先验,判"学会"永远走日常四维 + 间隔环。

- 蒙对一次不判掌握;真会连对达阈;手抖单错不掉出掌握(BKT 行为单测)。
- placement 15~25 题内收敛,出热力图 + 起点线;过下游能跳上游。

## 13. 掌握之后:推进环与路径引擎(地基验证扎实后如何继续)

当某学生**当前时间点之前的语法点经一段时间验证为掌握良好**后,系统从「诊断/补洞」切到「**推进**」模式。科学依据:**i+1 可理解输入(Krashen)/ 最近发展区(ZPD)+ 掌握学习(Bloom)+ 间隔保持(Ebbinghaus)**。注意:**配比从"补洞为主"切到"推进为主",用的是同一套图谱与掌握学引擎。**

### 13.1 推进环:三股流按比例交织

每日内容 = 三股流混合(比例随学情个性化,走后台可配):

| 流 | 默认占比 | 内容 | 依据 |
|---|---|---|---|
| ① 新点推进(i+1) | ~70% | 沿译林序学**刚好高一点**的下一语法点 | 最近发展区 |
| ② 间隔维持 | ~20% | 已掌握点按 SM2 长间隔**用新题抽测** | 掌握≠永久,防遗忘 |
| ③ 综合运用 | ~10% | 多点揉进长难句/写作/真题 | 单点会 → 会用 |

**关键:已掌握点不丢弃,进"长间隔维护队列"。** 间隔复测过 → 间隔继续拉长(近零成本维持);复测崩 → 即时召回到①。复用 `vocabulary_service.sm2`,语法点照搬。

### 13.2 优先级引擎:下一个学什么

不死按课本顺序,动态选**最高价值且已解锁**的点:

```
下一点价值 = 已解锁(先修已掌握)
            × 课程临近度(译林当前进度)
            × 考点权重(中考/期末频次·分值)
            × 尚未掌握
```
- **先修解锁**:KP 树 + 单元顺序判定,前置没过不放出。
- **考点权重**:同为未学,优先考得多的(对接真题/考纲)。
- 每次作答 / 上传错题真题 → 图谱实时更新 → 优先级重排。

### 13.3 个性化节奏(强生提速 / 弱生夯实)

- **跳测(curriculum compaction)**:对即将学的新单元先做迷你 placement,**已会的跳过**,只学洞 —— 强生不被课本节奏拖住。
- **拔高(enrichment)**:更难的迁移题 / 真题难题 / 跨点综合 / 超纲挑战。
- 弱生反向:① 占比下调、维持/补洞上调,慢而稳。

### 13.4 从单点掌握爬向综合运用(Bloom 上行,接已有模块)

```
单点语法(R10)
 └→ 句法综合:长难句(多点叠加的真实句)
     └→ 产出综合:写作精修(写作里正确用语法)
         └→ 应用综合:真题仿真(R2) / 错题闭环(R3) 的考试情境
```
"后续"不是无限学新语法点,而是 **点 → 句 → 篇 → 考** 逐级整合,语法成为读写考底层能力。

### 13.5 对齐里程碑 + 定期回看

- 按 期中/期末/中考 排进度,临考加重相关考点与综合运用。
- 周期**学情报告**(复用 dashboard/weekly_report):展示掌握热力图推进 + 维持情况 + 下一步计划,透明可解释。
