# R5 技术方案 · 词汇并入(词力通:词条挂 KP/真题/错题 + 背词来源收敛 + 通用词库)

> 依据:[重构-KP优先-需求分析.md](重构-KP优先-需求分析.md) 体系⑥ + 路线图 R5;承接 R0(`knowledge_nodes`)、R1(`unit_node`)、R2(`platform_question`)、R3(`wrong_record`)、R4(`student_kp`)。
> 原则:复用现有 `VocabularyWord`/`VocabularyLearning`/`CurriculumWord`/背词 SM-2;**扩字段 + 加边表 + 通用词库表**,不破坏现有背词前台/小程序。

---

## 0. 现状关键事实(已核实)
- `VocabularyWord`(d5)= 全局词典,有 `phrases`(JSONB) 但**无 type/频率/星级/source**;无词↔KP/真题/错题边。
- `VocabularyLearning`(d5)= 个人背词 SM-2(level/interval/ef/next_review/is_wrong)。
- `StudentVocabCandidate`(d5)= P2 候选词,仅 `source` 字符串(paper/wrong_question/manual),**无指向 node/题/错题**。
- `CurriculumWord`(d4)= 单元↔词(is_core);`curriculum_service.persist_unit` 生成单元时建。
- 背词来源:P1 当前学期教材词 / P2 候选 / P3 过往学期 / 全局回退(`vocabulary_service._ordered_new_words`)。
- **无通用词库表**(vocab_list)。词汇**完全未接** knowledge_nodes/student_kp/platform_question/unit_node。

---

## 1. R5 范围【按决策:词↔KP/真题/错题三边全建 + 通用词库(API+脚本+后台页)】
1. **词条扩展**:`VocabularyWord` 加 `type`(word|phrase)、`source`、`frequency`、`star`。
2. **三种边**:`vocab_node`(词↔KP)、`vocab_question`(词↔平台/上传题)、`vocab_wrong`(词↔错题事件);均多对多。
3. **通用词库**(平台域,超管维护):`vocab_list` + `vocab_list_item`(rank/frequency/star);导入权威考纲表脚本 + 真题/教材频率增强;admin API + 后台管理页。
4. **背词来源收敛**:背词新词来源 = ① 个人体系命中词(`student_kp` in_scope node → `vocab_node` → 词)② 可加选通用词库(`vocab_list_item`)③ 保留教材词/候选/过往。来源细化(候选补 node/question/wrong 指向)。

## 2. 新增 / 改动

### 2.1 扩 VocabularyWord(迁移 m87)
`type varchar(12) default 'word'`(word|phrase)、`source varchar(16)`(seed|ai|textbook|exam|import)、`frequency int null`(词频排名)、`star smallint default 0`(考频星级)。

### 2.2 三种边表(d18_vocab_kg.py)
- `vocab_node(word_id, node_id)` PK;relation/source。
- `vocab_question(word_id, q_scope, question_id)` PK;source(stem|option|explanation)。
- `vocab_wrong(word_id, wrong_record_id)` PK(错题事件词)。

### 2.3 通用词库(d18 或 d19_vocab_list.py)
- `vocab_list(id, name, exam_level, source_type, status, maintained_by, ...)`。
- `vocab_list_item(list_id, word_id, rank, frequency, star, verified)` PK(list_id, word_id)。

### 2.4 服务 `vocab_kg_service.py`(新)
- `attach_node/attach_question/attach_wrong`(原子 upsert 边)。
- `derive_unit_vocab_nodes(db, unit_id)`:单元核心词 × 单元 node(`unit_node`)共现 → `vocab_node` 边(教材批量派生)。
- `personal_kp_words(db, student_id, limit)`:`student_kp`(in_scope)→ `vocab_node` → 未掌握词(背词来源收敛核心)。

### 2.5 通用词库服务 `vocab_list_service.py` + 导入脚本
- `import_list(name, items)` / `list_lists` / `list_items` / `upsert_item`;脚本 `scripts/import_vocab_list.py`(导入考纲表)。
- 真题/教材频率增强:`recompute_frequency(list_id)`(按 vocab_question/curriculum_words 计数 → star)。

### 2.6 背词来源收敛(改 `vocabulary_service`)
`_ordered_new_words` 加来源:**P1 个人体系命中词**(personal_kp_words)优先;通用词库作可加选(学生设置 opt-in)。保留教材/候选/过往兜底。来源面板可分类。

### 2.7 Admin API + 后台页
- `GET/POST /admin/vocab-lists`、`/vocab-lists/{id}/items`(超管维护)。
- 前端 `frontend/admin` 加「通用词库管理」页(导入/查看/编辑 star)。

### 2.8 接线(additive)
- `persist_unit` 生成单元后 → `derive_unit_vocab_nodes`(教材词挂 node,防御式)。
- 真题导入(`import_real_question`)→ 词挂题(`vocab_question`,可选 best-effort)。
- 错题(`record_wrong`)→ 词挂错题(`vocab_wrong`,best-effort)。

## 3. 决策点【✅ 已定 2026-06-17】
- **R5-A = 扩 VocabularyWord**(加 type/source/frequency/star;复用现有词典与背词逻辑)。
- **R5-B = 词↔KP/真题/错题三边全建**。
- **R5-C = 通用词库:表 + 导入脚本 + admin API + 后台管理页 全做**。
- 背词来源收敛 = 个人体系命中词 + 可加选通用词库(§6 决策 C)。

## 5. 验收
- 词条有 type(word/phrase);词↔KP/真题/错题边可建可查。
- 教材单元核心词自动挂该单元 node(共现派生)。
- 背词新词来源收敛:个人体系命中词优先 + 通用词库可加选;教材/候选/过往兜底不破。
- 通用词库可导入/查/改(超管),后台页可用。
- 旧背词/SM-2/媒体/前台不受影响;全量回归绿(7 个既有 .env/陈旧失败无关,见 [[test-env-gotchas]])。
