# 长难句 L7:来源②③(教材/上传)+ 后台管理页

收尾 L1–L6 遗留两项。**无新表/迁移** —— `long_sentence` 模型已预留三源指针:
`source_kind ∈ (platform_real|textbook|uploaded)`、`source_passage_id`(教材语料)、
`source_q_scope/source_question_id`(上传题)、`scope/owner_id`(平台域 / 学生个人域)。

## 决策(已确认)

| 项 | 决策 | 说明 |
|---|---|---|
| ② 教材语料来源 | **平台 Passage** | `scope='platform'` 且 `kind ∈ (reading_text, dialogue)` 的 `passage.text`;`source_kind='textbook'`、`source_passage_id=passage.id`、生成句 `scope='platform'`。当前空(冷启动,同 platform_real),运营导入阅读篇章后自动生效 |
| ③ 上传范围 | **仅学生上传→个人域** | 扫 `uploaded_question(owner_scope='student').stem`;`source_kind='uploaded'`、`source_q_scope='uploaded'`、`source_question_id=uq.id`、生成句 `scope='student'`、`owner_id=该生`。`list_published` 已按 scope+owner 过滤 → 只自己可见 |
| ②③ 触发 | **后台批量任务** | 沿用 platform_real 的"独立后台任务"范式:`extract_from_textbook` / `extract_from_uploaded` + `run_extract` 调度(读 `long_sentence.sources` 配置)+ admin extract 端点加 `source` 参数 + 脚本 `--source` |

## 实现分步

### L7.1 service 三源抽取(后端 + 测试)
- 抽公共 `_persist_one(db, st, *, text, scope, owner_id, source_kind, source_q_scope, source_question_id, source_passage_id, min_words, dry_run)`:切句→长句判定→`analyze_sentence`→建 `LongSentence`→`match_kp` 挂句法 node / 落候选。`extract_from_platform` 改调它(行为不变)
- `extract_from_textbook(db, *, limit, min_words, dry_run, only_passage_ids)`:扫平台 Passage(reading_text/dialogue,text 非空),按 `source_passage_id` 幂等跳过
- `extract_from_uploaded(db, *, owner_id=None, limit, min_words, dry_run, only_question_ids)`:扫学生 UploadedQuestion(stem 非空),按 `source_question_id` 幂等;`owner_id` 限定单生
- `run_extract(db, *, sources=None, ...)`:`sources` 缺省读配置 `long_sentence.sources`;`platform_real→extract_from_platform`、`textbook→...`、`uploaded→...`,合并 ExtractStats
- 脚本 `extract_long_sentences.py` 加 `--source {platform_real|textbook|uploaded|all}`(默认读配置)
- 测试:平台 Passage(reading_text+LONG)→ textbook 句(scope=platform);学生 UploadedQuestion(LONG)→ uploaded 句(scope=student, owner_id)

### L7.2 admin extract 端点 source 参数(后端 + 测试)
- `POST /admin/long-sentences/extract?source=&limit=`:`source` 缺省=配置 sources;改调 `run_extract`
- 测试:`source=textbook` / `source=uploaded` 各抽出 ≥1 条

### L7.3 后台管理页 LongSentences.vue(前端,与 NodeResources.vue 同构)
- 三段:**抽取触发**(选 source + limit + 抽取,显示统计)/ **审核队列**(status+node_id 筛选,列 text/source_kind/syntax_points/status,发布·驳回)/ **配置**(sources/verify_types 多选 + min_words/required_pass,保存)
- `admin.ts` 加 `listLongSentences/extractLongSentences/reviewLongSentence/getLSConfig/setLSConfig` + 类型
- `router/index.ts` 加 `long-sentences` 路由;`MainLayout.vue` 加菜单「📐 长难句管理」

## 验收

- 学生上传题 → uploaded 长难句(个人域,仅本人 `list_published` 可见)
- admin 页可选源抽取 / 审核 / 配置;脚本可 `--source` 三源批量
- 回归:既有 521 passed 不破(除 7 项既有无关失败)
