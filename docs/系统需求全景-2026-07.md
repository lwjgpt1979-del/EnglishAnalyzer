## 1. 产品定位与商业模式

**好乐学Ai英语**:面向中小学生的 AI 英语因材施教平台(纯 AI 学习辅助工具,**非学科培训**——合规命门,见 §8)。

- **数据底座**:学生教材画像(版本/年级/学期)+ 知识点图谱(KP-First)+ 纸质错题/试卷拍照数字化。
- **方法论**:每条能力线都用「探针检测真掌握(而非刷题量)+ BKT/SM-2 掌握判定 + 间隔复习」;仿真题**派生自真题、不搬运真题**(版权红线)。
- **商业模式**:C 端学期会员(basic/pro/promax 档位 × 学期,权益矩阵锁功能)+ B 端机构激活码批量采购;家长代付为关键转化链路。
- **三角闭环**:学生学习 → 家长看周报/付费 → 老师(机构)分发作业拉新。

## 3. 学生端功能需求(六大能力线 + 支撑)

### 3.1 教材同步学习
- 按教材版本/年级/学期浏览课程单元(**只见 published**,发布闸门在 admin);单元 → 知识点讲解(AI 生成 6 维内容)→ 掌握度 → 关联练习/错题,学-练-错在同一 KP 下贯通。
- 教材主数据(`curriculum_catalog`)是全站「版本/年级/学期」候选的唯一真源(上架/下架)。

### 3.2 六大能力线(全部探针化)
| 线 | 核心机制 |
|---|---|
| **语法**(R10) | CAT 冷启动定级 → 识别/纠错/产出/迁移四维探针 + BKT(真会/蒙对/手抖可分)→ 每日推进环 → 隔期复测;纸质错题作先验 |
| **词汇**(词力通) | 语境化词卡 + 接收/产出双维探针 + SM-2;拍照取词「钉」进队列;跟读评分;独立打卡/补签;错词本 |
| **长难句** | θ 自适应推荐 → 分层主干解析 → 双探针理解检测 + 翻译自查 + 同结构迁移(验证真读懂);句内生词联动词力通 |
| **听力** | 分级精听 + 判分归集错题 + 影子跟读 + 薄弱句强化(会员) |
| **口语** | AI 多轮对话(场景可由在学单词/错题定制)+ 逐句纠错 + 发音评分 + 总结报告 |
| **写作** | 作文 AI 精修(按档位差异化)、写作能力训练(审题→限时写→分档诊断)、书面表达真题批改、阅读表达逐要点批改、写作错因本 |

### 3.3 练习与出题
- 按 KP 刷题、模拟考(整卷计时)、AI 自适应组题(按薄弱)、ProMax 自助出卷(周配额+加量包)。
- 铁律:仿真题从真题**反向派生**(同 KP/同题型/同干扰机制),KP 直生仅备选。

### 3.4 错题闭环(核心数据入口)
拍单题/拍整卷(1-9 图)→ OCR 四层管线拆题 → AI 归因到 KP → 错题中心 SM-2 复习队列 → 标记掌握;整卷错题可「练同类」反向生成。

### 3.5 学情与激励
- 今日学习计划(按薄弱度排任务)、学情诊断报告(可导出 PDF)、个人 KP 掌握图谱+趋势、退步预警。
- 打卡/连续火苗/XP 等级/勋章;学情周报推送家长(转化链路)。

### 3.6 商业化与账号
- 学期购/档位购/激活码兑换/优惠券/退款(7 天规则引擎)+申诉/发票;所有 AI 能力页挂 entitlements/Paywall。
- 合规:未成年监护人验证、注销 30 天冷静期、封禁申诉、协议/隐私;资料修改次数月配额。
- 消息中心/公告/FAQ/工单/意见反馈。

## 4. B 端需求

### 4.1 教师(小程序移动端)
认证 → 邀请码/二维码/短信绑学生(限额可配)→ 班级管理 → 看班级弱项 → **按弱项智能组卷**布置作业 → 自动判分入学生错题库 → 批改统计;可加入机构受其管理。

### 4.2 机构(Web 自助台)
公开入驻申请(admin 审核)→ 套餐(S1~S4,教师席位/出卷池/批改池)→ 老师管理与子额度 → **激活码采购**(档位×时长×数量,估价与计费同源)→ 批量续费 → 账单导出 → 机构学情健康度。

## 5. 平台运营后台需求(admin,9 模块)

### 5.1 内容生产流水线(最大块)
统一模式:**AI 生成 → 程序硬校验 → 人工审核/确认(唯一写库入口)→ 发布闸门**。
- 教材:目录主数据上下架、PDF→AI 生成单元内容(结构化/短文/词表)、生成任务队列、发布 draft/published。
- 真题/仿真:整卷上传解析(结构切分+LLM 兜底)、批量抽题、**题目层科学解析**(完形双轴=载体槽+线索类型、阅读 rc 技能+定位句;AI 建议暂存 → 人工确认保存)、挂 KP、反向生成仿真、整卷审核。
- 知识图谱:节点树 CRUD/别名归一/退休、候选 KP 审核、详解拆分、六维资源生产与版本对比、R10 判定校准看板。
- 词汇/长难句/口语/作文:词库、AI 配图/音频、长难句抽取回填(预算熔断)、口语场景、作文模板。

### 5.2 经营管理
用户/封禁申诉、教师认证、机构审核与套餐、定价(全部读 `system_configs`,**显示价=实扣价**)、权益矩阵、优惠券/限时活动价、退款申诉审核、发票、多收款主体/分公司/分成结算、财务看板。

### 5.3 增长获客(电销 CRM)
- 线索池(录入/Excel/爬取,查重合并、同号多机构、待补号)→ 认领/派单/公海 → 跟进 + 通话录音 ASR + AI 意向分析 → 看板/排行/来源统计。
- **地图获客**:百度/高德双源(独立 tab、AK 配置、每日配额熔断)+ **按区县每日自动采集**(目标省可配,覆盖进度表断点续采;乡镇级 API 不可行)。
- **教材版本地图**:地区→教材版本映射(省级默认+人工校对+地市例外,设区市选用制),支撑按地区精准销售。
- 呼叫中心多供应商(阿里云 CCC 等,webhook ?vendor= 并行)。

### 5.4 系统治理
- 模型配置/LLM 用量成本台账、TTS 音色语速/预热/用量、主题中心、敏感词、地区主数据、系统参数。
- **操作审计**(ASGI 中间件零埋点,全部 admin 写操作留痕,敏感字段脱敏)、**RBAC 账号与权限**(仅超管)、**定时任务健康看板**(task_run + 哑火检测 + 失败告警超管)。

## 7. 技术架构与外部集成

- **栈**:FastAPI + PostgreSQL(Alembic m133+)/ Vue3+Element Plus(admin/institution)/ uni-app Vue3(小程序 H5+mp-weixin)。
- **AI**:LLM Provider 抽象(DeepSeek/豆包/可切换,dev-mock 全链路离线可测);能力三类——生成(出题/内容/配图)、批改(作文/口语/翻译/造句)、分析(错因归类/解析建议/意向分析);OCR(错题/整卷/教材 PDF/拍照取词)、火山 TTS(预热+缓存)、发音评测。
- **外部**:微信登录/支付(多收款主体 APIv3 验签)、腾讯 COS、短信、阿里云 CCC、百度/高德地图 API、Sentry。
- **定时任务**(7 个 crontab,全部包 task_run 留痕+失败告警):签到提醒、退款 SLA、周报、到期预警、词汇/语法探针预生成、地图采集。

## 8. 横切铁律(全项目强制,详见 CLAUDE.md)

1. **运营可配置值必须读后台配置**(system_configs),禁写死遮蔽;显示价=实扣价同源。
2. **主数据上架/下架 + 按角色可见**:C 端只见 published;admin 全可管;单一主数据源。
3. **admin/机构列表页必须分页**(DB 层 offset/limit + total)。
4. **地区一律走 region 表**(region_service 解析行政区划码,存码不存名)。
5. **AI 只出建议,人工确认才写库**(内容生产线通则);线性 SVG 图标禁 emoji;主色 `--c-primary:#3d8bf5`。
6. **合规**:坚守"学习辅助工具"定性(禁"课程/辅导/提分"措辞);仿真派生不照搬;未成年保护+注销冷静期;PIPL(审计/脱敏/亲情代付)。
