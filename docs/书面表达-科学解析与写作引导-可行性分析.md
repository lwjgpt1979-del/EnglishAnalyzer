# 书面表达:科学解析 · 仿真模版 · 写作引导闭环 —— 可行性分析

> 与《完形填空综合方案》《AI整卷匹配-分题型科学解析-可行性分析》同系列。
> 铁律沿用:**AI 只出建议,真题解析人工确认才写库;评分权重/字数/量表等运营值读后台配置不写死。**

## 0. 结论先行(TL;DR)

1. 书面表达是全卷**唯一产出型题**(不是从 A/B/C/D 里选),不能"挂个考点"了事;要建一条闭环:
   **真题解析 → 仿真模版 → 引导写作 → AI 分维诊断 → 掌握更新 → 定向微练**。
2. **测量学骨架已在库里**:`wr-*` 24 个节点 = 国际写作测评的标准分析式评分维度(内容要点 / 语言准确 /
   语言丰富 / 结构连贯 / 书写规范 / 体裁格式),**直接当评分量表用,无需另造**。
3. **评分底座已在库里**:`reading_expression_service` 的「逐要点命中 + 内容/语言分 + `mastery_judge_service.log_answer`
   落 BKT」范式,扩成 5 维写作评分即可,不从零写。
4. **人在环**:真题的范文/要点/wr_codes/量表**人工确认唯一写库**(复用现有解析弹窗的 draft/confirm/force/审计);
   学生练习的 AI 评分是**形成性反馈**(标注"AI 评分",可教师复核改分)。

## 1. 书面表达考什么 —— 题型与评分的科学基础

### 1.1 题型
提示作文(guided writing):给**情景 + 要点(常以表格/中文提示给出)+ 词数 + 体裁**。
体裁 = 记叙 / 议论 / 说明 / 应用(书信·邮件·通知·便条·演讲稿·日记·看图)。对应 `wr-6-*`。

### 1.2 评分标准 = 真源(配置化,不写死)
- **中考**:要点分 + 语言 + 结构(**内容要点占大头**,漏要点是第一失分原因)。
- **高考**:**五档整体评分(holistic band)**——按整体印象定档。
- 系统**两套都出**:
  - **分析式(analytic)**:5 维分项 → 用于**诊断与教学**(可定位到 `wr-*` 子维);
  - **整体档(holistic)**:1 个档位 → **对齐考试**给学生真实预期。
- 量表权重、词数下限、档位边界 → 读 `system_configs`(配套后台入口),`xxx_service.get_writing_rubric()` 取,常量仅兜底。

### 1.3 为什么这样设计(测量学 / 二语写作研究依据)
| 设计 | 依据 |
|---|---|
| 分析式 + 整体档并存 | Analytic rubric 诊断性强、可教;Holistic 对齐真实考试评分。二者互补是写作测评共识。 |
| **要点覆盖(content point coverage)= 客观锚** | 提示作文的要点是**可逐条机检**的最客观维度;漏要点=最大失分源。作为评分"地基",压住 LLM 主观波动。 |
| 体裁图式(genre schema) | 每种体裁有固定篇章结构(书信:称呼→正文→结尾→署名;议论文:论点→论据→结论),**可教可迁移**,对应 `wr-4`/`wr-6`。 |
| 过程写作(pre-write→draft→revise) | 写作是过程,不只是判成品;搭框架 + 修改重评显著提分。 |
| 聚焦式纠错反馈(focused corrective feedback,Ferris/Bitchener) | 针对**特定错因类型**的直接反馈优于泛泛批改;→ 逐句批注标错因类型。 |
| 句型升格(sentence upgrading) | 把简单句升为复合句/非谓语/强调倒装,**高收益可训练**,对接 `wr-3`/`jf-*`。 |

## 2. 真题「写作解析对象」怎么科学拆(复制阅读/完形试点模式)

定义 `meta.analysis`(`kind="writing"`)结构 —— 与阅读的 `evidence`、完形的 `slot+clue` 平行:

```jsonc
{
  "kind": "writing",
  "genre": "应用文",                 // 记叙/议论/说明/应用
  "sub_format": "演讲稿",            // → wr-6-x
  "points": [                        // 要点清单:从 stem/要点表逐条抽,每条=可勾核项 → wr-1
    {"id": 1, "point": "懂感恩:举例说明"},
    {"id": 2, "point": "亲自然:说明理由"},
    {"id": 3, "point": "爱自己:如何做"}
  ],
  "main_tense": "一般现在时",        // 主时态/语域 → wr-2-1
  "wr_codes": ["wr-6-5", "wr-4-2", "wr-3-2"],   // 本题重点写作考点(从 wr-* 目录挑)
  "model_essay": "范文全文…",        // 范文(及答案版有则取;原卷版 AI 生成候选→人工确认)
  "point_map": {"1": "I'm grateful to…", "2": "…", "3": "…"},  // 要点↔范文句子映射(教学金矿)
  "target_expressions": [            // 目标高级句型/词块(升格靶,逐字取自范文)→ wr-3
    "Only by … can we …",
    "It is … that …"
  ],
  "pitfalls": [                      // 本题常见失分/中式英语陷阱 = 作文版「干扰项」,可教
    {"type": "时态", "trap": "演讲稿主时态用一般现在,学生易误用过去时"},
    {"type": "中式英语", "trap": "'爱自己' 直译 love myself 生硬,应 be kind to oneself"}
  ]
}
```

**校验(防幻觉,同 `evidence`/`clue` 子串思路)**:
- `target_expressions` 每条必须能在 `model_essay` 里**定位到**(`_norm` 子串,已有标点归一)——防 AI 编句型;
- `points` 非空;`wr_codes` 全在图谱(`_kp_codes_exist`);`genre`/`sub_format` 在枚举;`main_tense` 在枚举。
- **人工确认唯一写库**(复用 `confirm_analysis`,加 `kind=="writing"` 分支;支持 `force` 人工忽略误报,记 `validation_skipped`)。

## 3. 从解析到仿真模版(反向生成)

- **保持**:体裁 + 要点条数 + `main_tense` + `wr_codes` + 目标句型 + 难度;**变**:话题/情景。
- 复用 P0/P1 的反向生成骨架(`generate_fallback_sim`),输出**"写作"外壳**(`platform_question.question_type` 为 varchar,新题型免迁移),落**草稿待人工审**。
- 仿真题自带「要点清单 + 范文 + 量表」→ 直接可用于学生练习 + 自动评分,不需二次加工。

## 4. 学生写作引导闭环(前端,产出型专属流程)

| 步 | 做什么 | 科学意图 | 挂靠 |
|---|---|---|---|
| **S0 审题小测** | 选/填:体裁、要点条数、主时态、词数 | 前置治**漏要点**(第一失分源);过关才进写作 | `wr-1-1` |
| **S1 搭框架** | 每个要点 → 计划一句;从目标句型里选靶 | 过程写作 scaffold;结构先行 | `wr-1-2`/`wr-4-1` |
| **S2 写作** | 整篇输入(强)/逐句引导(弱),按学力自适应 | 降低产出焦虑 | — |
| **S3 AI 分维诊断** | 5 维分(**要点覆盖 checklist** + 语言准确率带**错因标注** + 丰富度 + 连贯 + 规范)+ **整体档** + **逐句批注** + **升格建议** | analytic 诊断 + holistic 对齐 + 聚焦纠错 | `wr-1..wr-5` |
| **S4 对照范文 + 修改重评** | 高亮要点↔范文句;学生改稿再评 | 过程写作闭环,提分关键 | `wr-*` |
| **S5 掌握更新** | 要点覆盖率/语言准确/用了几个目标句型 → BKT 更新 `wr-*`;错因→定向微练 | 个人图谱 + 定向补弱 | `mastery_judge_service` |

## 5. 评分可靠性(不胡说八道的保证)

- **量表锚定考试标准**(配置化);**要点覆盖=客观锚**兜底,压住主观项波动。
- 语言评分给 **量表锚点 + 范文 few-shot**,走 `complete_json`(截断升档 + 抖动重试 + `validate` 回调)降方差。
- 高风险可**多采样取共识**;AI 分**标注"AI 评分"**,教师可复核改分(不冒充权威分)。
- **人在环**:真题解析人工确认唯一写库;学生 AI 评分为形成性反馈,不进真题库。

## 7. 分期落地(切片,每片人工确认才写库)

- **W0 解析落地**:写作 `analysis` 对象 + 校验 + `suggest`/`confirm` 写作分发(后端)+ 解析弹窗写作形态(前端)。
  产物:能对一道书面表达真题做「要点/体裁/主时态/wr_codes/范文/目标句型/失分点」结构化解析,人工确认写库。
- **W1 仿真生成**:按解析反向生成同体裁·同要点数·同考点的写作仿真(草稿待审)。
- **W2 学生写作 + 评分**:写作练习页 + AI 5 维分维诊断(扩 `reading_expression`)+ BKT 更新 `wr-*`。
- **W3 闭环增强**:S0 审题小测前置 + S4 范文对照/修改重评 + 错因定向微练 + 高级句型升格练。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| LLM 评分方差 | 量表锚 + 范文 few-shot + 多采样共识;**要点覆盖客观锚**兜底 |
| 范文缺失(原卷版) | AI 生成范文候选 → **人工确认**;或从"及答案"版取 |
| 学生漏要点(主因) | **S0 审题小测前置强制** |
| 中式英语难判 | 错因分类标注 + 教师复核 |
| 产出型输入门槛 | 逐句引导模式 + 目标句型脚手架,按学力自适应 |
