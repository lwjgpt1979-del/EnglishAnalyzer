> v1(2026-07-05)。前置:《真题模块分析与仿真落地-可行性报告》《AI整卷匹配-分题型科学解析-可行性分析》。

## 一、定位与数据底座(实测)

- **权重**:近5年完形 **721 题、占 21%**(仅次于阅读24%、单选22%);全库 2,141 道。资源投入按此权重排第三优先。
- **存储就绪** ✅:导入时已逐空一行(`platform_question`),短文一份(`block_id→Passage`);练习端已带短文上下文渲染。
- **核心测量学判断**(本方案一切设计的出发点):完形四选项**同词性**,词性(载体)区分度≈0;**真构念是「语境线索捕捉」**,且按线索跨度分层(句内/跨句/全篇,Bachman 完形约束跨度分类)。
  - 反例即证:「Happily/Usually/Unluckily/Hopefully」挂「副词词义辨析」= 把载体当构念——学生错这空该练**抓转折/情感基调**,不是背副词表。

## 二、解析层:双轴解析对象 ✅(2026-07-05 落地,11 tests)

每个空一份,存 `platform_question.meta.analysis`(免迁移,kind="cloze"):

| 字段 | 含义 | 谁判 | 防胡说机制 |
|---|---|---|---|
| `slot` 载体槽 | 副词/连词/介词/代词/交际用语/动词形式槽 | **程序确定性判**(选项同词性即定,零 LLM;拿不准 None) | 判定即校验 |
| `clue_type` 线索类型 | **真构念**,7 类封闭枚举:句内固定搭配/句内语法约束/跨句逻辑关系/跨句词汇复现/全篇情感基调/指代与人物追踪/情景交际惯用 | LLM 建议 | 枚举外一票打回 |
| `clue` 线索句 | 决定答案的原文句 | LLM 建议 | **必须原文子串**(空白归一),幻觉打回 |
| `kp_codes` 考点 | **线索轴为主**(rc-4*/rc-6*/情景交际;句内类可 cf/jf) | LLM 从受控目录挑 | 编码必须在图谱 |
| `distractor_types` 干扰项错因 | 6 类封闭枚举(近似词误配/以偏概全/过度推断/无中生有/张冠李戴/因果倒置) | LLM 建议 | 枚举校验 |

**干扰项为什么必须标**(三重意义):
1. **错因级学情**:选 B 和选 C 是两种病——错因标注让诊断从「错了这空」深到「你的 Top 错因 = 情感基调误读」;
2. **变式保真**:干扰项决定难度与区分度,变式若随机造干扰项 = 题干像母题、含金量不像;
3. **教学反馈**:「你选的 B 错在'张冠李戴'」——6 类陷阱模式有限、可训练、可迁移,正是前端学习策略的素材。

**写库铁律** ✅:AI 只出建议(`suggest_analysis` 分发,完型走双轴);**人工逐空确认(`confirm_analysis`)是唯一写库入口**,服务端重校验,带确认人/时间。admin 弹窗双模式已就绪(载体槽程序预填、线索类型下拉、线索句、考点编码、A–D 错因下拉)。

## 三、标注运营流程(人机协同,完形版 Phase A)

**C0 · 提示词调优(配置级,零代码)⬜**
后台「知识点 AI 提示词」完型项:关注分类**加 rc-4/rc-6 子树 + 情景交际**;提示词改为「先判线索类型,再挑对应考点;**同词性选项禁止只挂词性词义辨析类**」。→ 一键挂知识点的建议质量立涨。

**C1 · 校准(阶段0)⬜**
抽 **20 空**(近5年卷)走「解析」弹窗:AI 建议 → 人工改/确认。验收:**字段免修改率 ≥85%**(载体槽因程序判应≈100%;主要看 clue_type/clue),不达标改提示词重跑。

**C2 · 放量 ⬜**
近5年 721 空优先;机器校验(子串/枚举/编码)前置打回,人工只看过关件。
**联动挂 KP(小改,待做)⬜**:确认解析时把 `kp_codes` 顺手写入 `platform_question_kp`(人工已确认,不该让运营再点一遍「+知识点」)。

## 五、练习与学情层

- **练习** ✅:物化完形题带 passage 上下文;逐空作答、选项判分、答错落 `student_kp.wrong_count`(线索轴 KP)→ 弱项自适应捞出。
- **错因级学情** ⬜:练习记录已存 `user_answer`;有了 `distractor_types`,答错即可归因错因类型 → 报表「Top 错因:以偏概全 ×7」。依赖:解析标注量。
- **难度校准** ⬜:先用命题难度先验,作答量足后按 CTT 通过率/选项被选率回填——**顺带鉴定干扰项质量**(无人选的干扰项=废选项,题目实际三选一)。

## 六、前端学习策略层(数据驱动,标注量达标才开)⬜

素材全部来自已确认解析的真题及其派生仿真,**不凭空造内容**:

1. **线索类型训练包**:按 `clue_type` 聚合——「转折信号词训练」「情感基调题包」「指代追踪题包」;开包条件:该类型已确认解析 **≥20 空**(不然空页面)。
2. **练习反馈升级**:答题后高亮**线索句** + 「你选的 X 错在'{错因}'」——教识别陷阱模式,可迁移。
3. **学习路径**:先按弱线索类型练**单空微题**(反向生成/真题派生),再整篇限时(先分解后整合,刻意练习原则)。
4. **学情页**:完形分项 = 线索类型 × 正确率(不是「完形 62 分」,而是「跨句逻辑 85%、情感基调 40%」)。

## 七、数据流总览

```
真题完形(逐空一行,共享 Passage)
  → C0 提示词调优 → AI 双轴解析建议(载体槽=程序判;线索句=子串校验;枚举/编码校验)
  → 人工逐空确认(唯一写库:meta.analysis + 联动挂 kp_codes)
  → 仿真:单空变式/整组改写/反向生成(硬约束:同线索类型+同载体槽+同错因策略;draft→人审→发布)
  → 练习(带短文上下文;答错落线索轴 KP 弱项)
  → 学情(线索类型×正确率;Top 错因)
  → 前端训练包(按线索类型组织;线索句高亮反馈)
```

## 八、执行顺序与验收

| 步 | 内容 | 验收 |
|---|---|---|
| C0 | 完型提示词+关注分类调优(后台配置) | 同一张卷重跑「一键挂」,人工评建议轴向正确率 |
| C1 | 20 空校准 | 字段免修改率 ≥85% |
| C2 | 近5年 721 空放量 + 确认联动挂 KP | 完形逐空标注率;机器打回率监控 |
| C3 | 整组改写注入解析 + 反向生成按线索类型参数化 + 30 组对照盲评 | 盲评保真度显著优于对照 |
| C4 | 错因级学情报表 + 前端线索类型训练包 | 各 clue_type 确认量 ≥20 才开包 |

**风险提示**:C1 若 clue_type 一致率低,优先怀疑枚举边界不清(如「跨句词汇复现」vs「全篇情感基调」重叠)——收敛办法是给枚举写判别规则示例进提示词,而不是加枚举。
