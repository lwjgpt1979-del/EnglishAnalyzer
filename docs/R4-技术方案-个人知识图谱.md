# R4 技术方案 · 学生个人知识图谱(物化 student_kp + 多来源 + 知识地图)

> 依据:[重构-KP优先-需求分析.md](重构-KP优先-需求分析.md) 体系⑦ + 路线图 R4;承接 R0.5(`student_kp`/`answer_log` 窄表)、R1(`unit_node` 教材↔节点边)、R3(`student_kp` 已写练习计数/掌握)。
> 原则:旧 `student_kp_mastery`/`kp_mastery_snapshots`(kp_key 台账)保留供现有诊断/小程序;R4 在**新 node 维度**物化 `student_kp` 为个人图谱,新出图谱 API。前端学生端是小程序(仓外),R4 交付 API;后台 admin 图谱页可选。

---

## 0. 现状关键事实(已核实)
- `student_kp`(R0.5)已建,R3 只写 `practice_count/wrong_count/last_practice_at`(log_answer)、`mastery=1`(judge);`source_tags` 恒 `['practice']`、`in_scope` 恒 `true`——**未落地"选教材纳入 / 多来源 / in_scope 语义"**。
- 选教材偏好存 `User.preferred_textbook_version/grade/semester`(`POST /auth/profile` 写),**不触发任何 student_kp 纳入**。
- 教材应学全集 KP 可由 **教材→`curriculum_units`(version/grade/semester)→`unit_node`→node** 算出(R1 已建边)。
- 旧 `kp_mastery` 树/趋势 API(`/kp-mastery/`、`/kp-mastery/trend`)基于 kp_key 字符串 + `kp_mastery_snapshots`;小程序"我的知识地图"读它。
- `answer_log`(R3 已写)可作 node 维度趋势数据源。

---

## 1. R4 范围
1. **选教材→批量纳入** `student_kp`:选/换教材 → 该教材单元的 node 全集批量 upsert 进 `student_kp`(`in_scope=true`,`source_tags += 'textbook'`)。
2. **多来源标签**:KP 进入个人体系的来源累积到 `source_tags`(textbook / wrong_hit / real_hit / practice / vocab);提供原子追加(去重)。
3. **知识地图 API**(新,node 维度):默认**只亮已练/已错**(practice_count>0 或 wrong_count>0),教材全集(in_scope 未练)**折叠**、`include_all=true` 展开;带 summary(全集/已练/薄弱/已掌握)。
4. **掌握度趋势**:node 维度趋势(数据源见决策 R4-B)。
5. **接线**:profile 更新教材 → 纳入;错题命中 → `source_tags+='wrong_hit'`;(真题命中 → 'real_hit' 可选)。

> 不动旧 `student_kp_mastery`/snapshots 与旧 `/kp-mastery` API(小程序现读它,切换单列);R4 新 API 并行。

## 2. 新增 / 改动

### 2.1 个人图谱服务 `student_graph_service.py`(新)
- `enroll_textbook(db, *, student_id, textbook_version, grade, semester)`:
  教材 → `curriculum_units` → `unit_node` → node_ids → 批量 upsert `student_kp`
  (`in_scope=true`,`source_tags` 追加 'textbook';已存在不覆盖练习数据)。返回纳入数。
- `add_source(db, *, student_id, node_id, tag, in_scope=None)`:原子把 tag 追加进 `source_tags`
  (去重,类似旧 sources merge);可顺带置 in_scope。供命中并入复用。
- `get_graph(db, *, student_id, include_all=False)`:返回个人图谱条目
  (node 名/轴/node_kind + mastery + practice/wrong_count + source_tags + status)。
  默认只返 practiced∪wrong;`include_all` 加 in_scope 未练的(状态=未学)。
- `graph_summary(db, *, student_id)`:全集数/已练/薄弱(wrong>0且未掌握)/已掌握。

### 2.2 趋势 `student_kp_trend`(决策 R4-B)
基于 `answer_log` 按 node + 日聚合 accuracy(node 维度,新);或复用旧 snapshots。

### 2.3 API `student_graph.py`(新,get_current_user)
- `GET /student-kp/graph?include_all=false` → 知识地图(默认只亮已练已错 + summary)。
- `GET /student-kp/trend?node_id=&days=30` → 某 node 掌握趋势。
- `POST /student-kp/enroll`(或随 profile 自动)→ 手动重同步教材纳入。

### 2.4 接线(additive,不破坏旧)
- `POST /auth/profile` 写教材偏好后 → 调 `enroll_textbook`(防御式)。
- R3 `record_wrong` / 整卷命中 → `add_source(node, 'wrong_hit')` + in_scope=true。

---

## 3. 决策点【✅ 已定 2026-06-17】
- **R4-A = 自动 + 显式端点**:profile 更新教材自动纳入(防御式)+ `POST /student-kp/enroll` 显式重同步。
- **R4-B = answer_log 新 node 维度趋势**(贴 student_kp 统一;answer_log 已有数据)。
- **R4-C = 只交 API**(学生端小程序仓外;后台 admin 图谱页暂不做)。

---

## 4. 分步实施(每步可验收、可独立提交)
- **R4.1** `student_graph_service`(enroll_textbook 批量纳入 + add_source 原子追加)+ 单测(纳入 in_scope/source_tags、追加去重、不覆盖练习数据)。
- **R4.2** `get_graph` + `graph_summary`(默认只亮已练已错 / include_all 展开全集 / status 分类)+ 单测。
- **R4.3** API `/student-kp/graph` + `/enroll` + profile 自动纳入接线 + 错题命中 add_source('wrong_hit')+ HTTP 测试。
- **R4.4** node 维度趋势(answer_log 聚合)+ `/student-kp/trend` + 单测。
- **R4.5** 端到端验收(选教材纳入全集→练习/错题→图谱默认亮弱点·展开全集→趋势)+ 串测。

---

## 5. 验收
- 选/换教材 → 该教材 node 全集进 `student_kp`(in_scope,source_tags 含 textbook)。
- 命中(错题/真题)→ source_tags 追加对应来源(去重);多来源并存。
- 知识地图默认只亮已练/已错,全集折叠可展开;summary 正确(全集/已练/薄弱/掌握)。
- node 维度趋势可查(answer_log)。
- 旧 `student_kp_mastery`/`/kp-mastery`/诊断不受影响;全量回归绿(7 个既有 .env/陈旧失败无关,见 [[test-env-gotchas]])。
