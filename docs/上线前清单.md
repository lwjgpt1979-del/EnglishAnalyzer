## A · 微信小程序申请（用户做）

**1. 注册主体**
- 个人开发者：限制多（无法用微信支付、无法对接对公）→ 测试可、上线收费不行
- 企业主体：营业执照 + 对公账户 → **推荐**

**2. 注册小程序账号**
- URL: https://mp.weixin.qq.com/wxopen/waregister?action=step1
- 流程：填邮箱 → 验证 → 选主体类型 → 提交资料 → 等审核（个人 1 工作日，企业 3-5 工作日）

**3. 拿到 AppID**
- 登录 mp.weixin.qq.com → 开发 → 开发管理 → 开发设置
- 复制 **AppID**（格式 `wxXXXXXXXXXXXXXXXX`）和 **AppSecret**

**4. 替换占位符**
- 文件 `frontend/miniprogram/src/manifest.json`，2 处：
  ```diff
  - "appid" : "wx__REPLACE_WITH_REAL_APPID__"
  + "appid" : "wxYOUR_REAL_APPID"
  ```
  顶层和 `mp-weixin` 块都要改。
- 后端 `.env`：`WECHAT_APPID=` 和 `WECHAT_APPSECRET=`

**5. 类目选择**
- 后台→设置→基本设置→服务类目
- 推荐：**教育 → 在线教育**（需要：办学许可证 ICP 不强制；但 K12 学科类内容需要"教育资质证明"，比如教师资格证 + 营业执照经营范围含教育）
- **风险**：2021 双减后 K12 学科类对外销售受限。MVP 阶段建议先选"教育 / 学习辅助工具 / 学习用品"，不直接卖 K12 学科课程，规避监管。

## G · 数据库自动备份（强烈建议）

**最简方案：** 在生产服务器加 cron 每日全量备份至 COS。

```bash
# /etc/cron.daily/pg_backup
#!/bin/bash
TS=$(date +%F)
docker exec enggramer-postgres pg_dump -U enggramer enggramer | gzip > /tmp/db-$TS.sql.gz
# 上传至 COS（用 coscmd 或 aws cli S3 兼容）
coscmd upload /tmp/db-$TS.sql.gz /backups/db-$TS.sql.gz
find /tmp -name "db-*.sql.gz" -mtime +7 -delete
```

保留 30 天 COS 副本 + 7 天本地副本即可。

## I · 微信支付（如做收费版本）

**预备资料（每项都需要 5-20 工作日）：**
1. 营业执照 + 法人身份证
2. 对公账户（开户许可证 / 进账单截图）
3. 经营场所照片（门头/办公场所）
4. 客服电话 + 售后政策

**申请路径：**
1. 注册：pay.weixin.qq.com → 立即开通 → 普通商户号
2. 资质审核：1-3 工作日
3. 签约：API 平台 → 关联小程序 AppID → 启用支付能力
4. 获取：
   - **MCH_ID**（商户号）
   - **API V3 Key**（API 密钥 → 32 字符随机串，自己设）
   - **商户证书**（apiclient_cert.pem + apiclient_key.pem + 证书序列号）
5. 填入 `.env`：`WECHAT_PAY_MCH_ID/API_KEY_V3/CERT_SERIAL/PRIVATE_KEY_PEM`
6. notify_url 在公网可达 + HTTPS

**MVP 上线初版可以暂不接支付**（屏蔽前端"立即升级"按钮，纯免费版上线 → 验证产品 → 拿到一些用户后再上支付）。
