## 一、核心结论：命门在「学习工具 vs 学科培训」的定性

本产品按**学习辅助工具**设计（纯 AI、无真人直播/一对一授课、学生自助），这是双减下可辩护的定位（类比百词斩、有道词典、错题本类工具，不属于"学科类校外培训"）。

双减严管对象：**义务教育阶段（小学+初中）学科类校外培训**——真人授课、直播、一对一、按课时收费。本产品均无。

**真正风险不在功能，在"措辞与包装"**：早期文案把工具说成"卖课程/应试培训"，会把可辩护的工具拖向被监管的学科培训。目标用户为**初中（义务教育阶段）**，正处最严区，措辞须谨慎。

## 三、已落地的整改（本次，纯文案/条款，不动功能）

1. **去"课程"措辞**：
   - "按学期购买课程内容/购买课程" → "按学期解锁知识点讲解与练习资料/学习资料"
   - "解锁该学期全部单元课程内容" → "…知识点讲解与练习资料"
   - 引导页"的课程内容" → "的知识点讲解与练习"
2. **去"应试"措辞**：作文页/导航"应试写作训练" → "写作能力训练"
3. **去"辅导"措辞**：教师页"建议优先辅导" → "建议优先强化练习"
4. **协议/隐私加产品性质声明**（草拟，待律师定稿）：
   - 用户协议新增「产品性质声明」：本产品为学习辅助工具，不提供学科培训/直播授课/一对一辅导，会员为软件订阅权益非培训课时费。
   - 会员档位条款去掉写死价格，改"以小程序最新展示为准 + 学习工具订阅"。
   - 隐私政策引言增加同口径产品性质 + 未成年人从严保护表述。

## 四、仍需你/律师处理（未落地）

1. **协议/隐私正文定稿**：本次为草拟防御条款，须法律专业人员审核、替换【运营方公司全称】等占位符。
2. **预收费模式**：✅ **已决（2026-06-15，路径 A）：按"学习工具订阅"定性，不设预收时长上限，6 个月/份、可买多份照常销售。** 依据："不超 3 个月/60 课时"上限约束的是学科类校外培训机构的培训/课时费，软件工具订阅（年/半年会员为行业惯例）不适用。前提：协议已写明"软件订阅权益非培训课时费"、措辞去培训化、无真人授课。**唯一关键待办：律师对"工具 vs 培训"定性拍板。**（路径 B 备选：若被认定为培训，则需将单次有效预收时长压到 ≤3 个月——剩余 >90 天禁止再购 + 限份数，会削弱长期会员模式，非当前选择。）
3. **营业执照经营范围**：避免"学科类培训"；建议"教育科技/软件开发/信息技术咨询"。
4. **小程序服务类目**：选"教育 → 学习工具/学习辅助"，不选 K12 学科培训（上线清单已注明）。
5. **宣传/广告**：禁用"提分/名师/保过/押题/一对一"等校外培训敏感词。
6. **仿真题/教材版权**：坚持"只做解读、派生不照搬"（已归档 D-003 等）。
