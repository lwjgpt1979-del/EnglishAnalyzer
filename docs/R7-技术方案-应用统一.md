> 原则:把应用层各功能的错题/上传口径统一到前 6 期骨架;旧表/前台保留,接线 additive 防御式。

## 0. 现状关键事实(已核实)
- **取材基本"有源"**:听力(种子库)、口语(预设场景+教材单元+词力通+课本原文)、词力通(R5)——不无源 AI 直生。**练习/自助出卷**仍 AI 生成/读 simulated_questions(题库冷启动空 → 本期不改,留后续)。**长难句**无功能(留后续)。
- **错题收口未统一**:整卷✅(R3 已接 match_kp+wrong_record);**单题拍照❌**(ocr.py 只写旧 WrongQuestion)、**作业⚠️**(有 classify 缺 match_kp/wrong_record)、**听力错题❌**(ListeningWrongQuestion)、**口语错题复习❌**(读旧 WrongQuestion)。
- **上传管线三分天下**:整卷有 split→classify→match_kp→wrong_record;单题/作业各写各的。
- 公共原子已成熟:`paper_split_service.split_paper_questions` / `kp_classifier_service.classify_kps` / `kp_match_service.match_kp` / `wrong_center_service.record_wrong` / `student_graph_service.add_source`。

---

## 1. R7 范围【决策后】
1. **公共 ingest 服务**(统一上传拆题管线):`ingest_service`
   - `ingest_parsed(owner_scope, owner_id, parsed, source_type)`:拆好的题 → `uploaded_question` + `match_kp` 挂 `uploaded_question_kp`(node)+ 错题 `record_wrong`(uploaded)+ `add_source`。供 单题拍照/作业/整卷 复用。
   - `record_wrong_answer(student_id, q_scope, question_id, kp_name=None)`:答错事件(无 OCR)→ `match_kp(kp_name)`→node + `record_wrong` + `add_source`。供 听力/口语/作业 答题事件复用。
2. **全渠道错题收口**(决策 R7-A):单题拍照 / 作业 / 听力 / 口语错题复习 → 经上面两原子进 `wrong_record`。
3. **取材"有源"确认**:听力/口语/词力通 取材已有源,不改;练习/自助改 platform_question **留后续**(R7-C)。

### 2.2 各渠道接入(additive,防御式)
- **单题拍照**(`ocr.py _run_ocr_pipeline`)— 闭 R3 遗留:OCR 拆出题 → `ingest_parsed(owner_scope='student', source_type='single')`(建 uploaded_question + wrong_record);旧 WrongQuestion 保留。
- **作业**(`assignment_service`):答错 → `record_wrong_answer(kp_name=该题KP)`。
- **听力**(`listening_service.submit_answers`):答错 → `record_wrong_answer`(听力题 id + KP 名若有)。
- **口语错题复习**(`speaking_dialogue_service._top_due_wrong`):读 `wrong_record`(status=open)替代旧 WrongQuestion。

### 2.3 不改

## 3. 决策点【✅ 已定 2026-06-18】
- **R7-A = 听力+口语+作业+单题拍照 全渠道错题收口**到 wrong_record。
